## 原則

1. **計算はプログラム、解釈はAI** — 資産・損益・指標・価格候補はすべて Python のテスト済みコードで計算
2. **AIがなくても動く** — AI分析は追加機能。AIが使えなくても資産計算・指標算出・ルールベース判定は正常に動作
3. **推測で埋めない** — 取得できないデータは「不明」と表示。出典と取得日時を必ず表示
4. **月額0円** — 無料枠を超える呼び出しは自動で行わない。有料が必要な機能は実装前に必ず報告
5. **最終判断は自分** — 自動売買はしない
