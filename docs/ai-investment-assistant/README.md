## 一番大事な3原則

1. **計算はプログラム、解釈はAI**
   評価額・損益・為替差損益・税金・PER などの数値は、すべてテスト済みのプログラムで計算します。
   Claude はその数値を「読んで」分析・説明・レポートを書く役割に限定します。
2. **データがなければ「なし」と表示する**
   取得できなかった値を推測で埋めません。すべての数値に「出典」と「取得日時」を持たせます。
3. **最終判断は自分**
   自動売買は実装しません。AIの判断は「提案」として理由・スコア・リスク・確信度とともに表示します。
