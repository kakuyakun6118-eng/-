# 5. 無料データソースの調査

**この章で決めること:** どのデータをどの無料サービスから取るか、制限・遅延・利用規約。

> 2026-11-13 時点の調査。FMP・Finnhub・Tiingo の制限は第三者サイトの情報を含み、資料間で食い違いがあります。
> **各サービスの登録時に公式の制限と規約を確認し、違いがあれば報告します。**

## 5.2 比較したが採用しない / 予備にするもの

| サービス | 判断 | 理由 |
|---|---|---|
| FMP Free | **予備** | 無料版は対象銘柄が約100のサンプル銘柄に限られ、財務諸表は有料との報告あり。保有銘柄が対象外の可能性が高い |
| Alpha Vantage Free | **予備** | 25回/日と少ないが、Tiingo障害時の米国株日足の予備に使える |
| J-Quants Light(1,650円/月) | 不採用(有料) | 日本株の最新日足が取れるが、0円方針のため。必要なら事前に相談(08章) |
| Yahoo Finance 非公式API | **使用禁止** | 公式APIではなく利用規約上の問題・仕様変更リスク |
| 証券会社サイト・株価サイトのスクレイピング | **使用禁止** | 利用規約違反のおそれ |
| SBI証券の自動ログイン・画面操作 | **使用禁止** | 規約違反・セキュリティリスク。CSVは自分でダウンロード |

## 5.3 SBI証券のCSV

SBI証券のWebサイトから、自分の口座データをCSVでダウンロードできます(自分のデータを自分で取得するので規約上の問題なし)。
対応を予定しているCSV(**正確な列はサンプルで確認してから実装**):

| CSV | 用途 |
|---|---|
| 国内株式の取引履歴(約定履歴) | 日本株の売買取引を登録 |
| 外国株式の取引履歴 | 米国株の売買・約定レートを登録 |
| ポートフォリオ / 保有証券一覧 | 保有数量の照合、日本株の現在値・投資信託の評価額 |
| 入出金・配当の明細(取得できる場合) | 現金・配当の登録 |

注意点:
- 文字コードが Shift_JIS の場合があるため自動判定
- SBI証券が列の構成を変更する可能性 → 取り込み前にプレビューし、想定外の列があれば取り込まずに警告
- 同じCSVを2回取り込んでも重複しない仕組み(`dedup_key`)

## 5.4 データ取得のルール

1. 無料枠の **80%** を安全上限とし、到達したら停止(01章 1.5)
2. 有料エンドポイントは呼び出せない作り(provider ごとに許可リスト)
3. 取得失敗・上限到達・未対応は、画面に **「不明」** と理由を表示(古い値を新しく見せない)
4. 取得データの再配布はしない(本システムは自分専用)
5. Tiingo の帰属表示など、規約が求める表記は画面に表示
