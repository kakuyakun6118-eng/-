# 5. 外部APIの調査・料金比較

**この章で決めること:** どのデータをどこから取るか、いくらかかるか、何が取れないか。

> **重要:** 料金・制限は 2026年11月13日時点の調査です。第三者サイトの情報を含むため、
> **契約・実装前に各社の公式ページで再確認**します。無料枠の条件は予告なく変わることがあります。

| 段階 | 日本株 | 米国株 | 月額目安 |

## 5.3 為替・マクロAPI

| サービス | 内容 | 料金 | 備考 |
|---|---|---|---|
| Frankfurter(ECB参照レート) | 主要通貨の日次参照レート | 無料・キー不要 | 1日1回(欧州時間午後)の公表。日中変動は取れない |
| FMP / Finnhub Forex | USD/JPY 等 | 各無料枠内 | 日中のレートが必要な場合 |
| FRED(セントルイス連銀) | 米国債利回り(DGS2, DGS10)、FF金利、CPI、失業率、GDP など | 無料(APIキー登録) | 非常に信頼性が高い |
| e-Stat(政府統計) | 日本のCPI・GDP・労働統計 | 無料(アプリID登録) | 項目の探し方にやや慣れが必要 |
| 日本銀行 時系列統計データ | 政策金利・マネタリーベース・短観など | 無料 | API提供形態を実装前に確認 |

## 5.4 ニュースの取得方針(課題あり)

日本語の企業ニュースを個人が適法・安価にAPIで取得できる選択肢は限られます。
スクレイピング(Webページの自動読み取り)は利用規約違反になりやすいため**行いません**。

**採用案:Claude API の Web検索ツール**
- Claude が検索 → 記事を読み → 要約し、**出典URLを引用として返す**
- 料金: 検索1,000回あたり約$10 + トークン料金(公式価格を実装時に再確認)
- 利点: 日本語・英語どちらも対応、出典が自動で付く
- 欠点: 毎回の費用、取得結果の網羅性は保証されない → 「AIが見つけたニュース」と明示

米国株は Finnhub / FMP のニュースAPI(見出し・URL)を併用します。

## 5.5 Claude API

| モデル | 用途(案) | 入力 / 出力(100万トークンあたり) |
|---|---|---|
| **Claude Opus 5.5**(`claude-opus-5-5`) | 個別銘柄の詳細分析・日次レポート(既定) | $4 / $20 |
| Claude Sonnet 5.5(`claude-sonnet-5-5`) | 料金を抑えたい場合の選択肢 | $2 / $10 |
| Claude Haiku 5.5(`claude-haiku-5-5`) | ニュースの分類・短い要約など大量処理の選択肢 | $0.10 / $0.50 |

※ 2026年11月時点の公式価格表に基づく。モデルの使い分けはご予算次第で決めます(10章で質問)。

### 費用の見積もり(Opus 5.5 を全処理に使った場合)
| 処理 | 1回あたり(入力/出力トークン) | 1回の費用 | 頻度 | 月額 |
|---|---|---|---|---|
| 個別銘柄分析 | 約20,000 / 4,000 | 約$0.16 | 20銘柄×週1回 | 約$13 |
| 日次レポート | 約25,000 / 5,000 | 約$0.20 | 毎日 | 約$6 |
| ニュース検索(Web検索込み) | 約10,000 / 2,000 + 検索5回 | 約$0.13 | 毎日 | 約$4 |
| **合計** | | | | **約$23(約3,500円)** |

### 費用を抑える工夫
- **プロンプトキャッシュ:** 毎回同じ指示文(分析ルール・投資方針)を再利用し、2回目以降の入力料金を大幅に削減
- **Batch API(一括処理):** 急がない週次分析は一括処理で料金約50%オフ
- **変化がない銘柄は再分析しない:** 株価・財務・ニュースに一定以上の変化があった銘柄だけ再分析
- **月額上限:** `api_usage` テーブルで集計し、設定した上限を超えたら停止して通知

## 5.6 データ取得で守ること

1. 各APIの**利用規約(個人利用・再配布禁止など)**を守る。本システムは自分専用で外部公開しない
2. 取得したデータはそのまま他人に配布しない
3. 呼び出し回数の上限を守るため、取得はサーバー側の定期ジョブにまとめ、画面表示はDBから行う
4. 取得失敗は `job_runs` に記録し、画面に「取得失敗」と表示(古い値を新しい値のように見せない)
5. APIを乗り換えられるよう `providers/` で共通インターフェースを定義する
