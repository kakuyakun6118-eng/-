# 0. 無料構成で実現できる機能・できない機能

**この章の目的:** 月額0円で「何ができて、何ができないか」を最初にはっきりさせます。

## 判定の記号

| 記号 | 意味 |
|---|---|
| ◎ | 無料で問題なく実現できる |
| ○ | 無料で実現できるが制約あり(遅延・頻度・範囲) |
| △ | 自動化は無料ではできない → **手入力・CSV取り込み・手動操作**で代替 |
| × | 無料では実現できない(実装しない。将来有料化する場合の選択肢は08章) |

> 料金・制限は 2026-11-13 時点の調査値です。一部は第三者サイトの情報で資料間に食い違いがあるため、
> 実装時に各公式ページで再確認し、違いがあれば報告します。

## 0.1 前提となる費用

| 項目 | 費用 | 説明 |

| Node.js / Python / SQLite / VS Code / Git | 0円 | すべて無料のソフトウェア |
| GitHub(コード保管) | 0円 | 無料プラン。**資産データ(DBファイル)はGitHubに上げない** |

| Claude Code | **既にご契約中のClaudeプランの範囲内**(追加0円) | Claude Code の利用にはClaudeの有料プラン(Pro等)が必要です。現在このClaude Codeをお使いなので、追加費用は発生しない前提です。プランの利用上限内で使います |

| 電気代 | わずか | 外出先からiPhoneで見る場合はPCの電源を入れておく必要あり |

**月額の追加費用: 0円**

## 0.2 機能別の判定

### A. 資産管理

| 機能 | 判定 | 実現方法 |
|---|---|---|
| 口座管理(特定・NISA成長/つみたて・旧NISA・銀行等) | ◎ | 手入力 |
| SBI証券の取引履歴CSV取り込み | ◎ | SBI証券サイトからCSVをダウンロード → アプリに取り込み(列定義はサンプルCSVで確定) |
| 取引の手入力(買付・売却・配当・入出金・両替・分割) | ◎ | 入力フォーム |
| 移動平均法による取得単価 | ◎ | Python で計算 + テスト |
| 実現損益・含み損益 | ◎ | 同上 |
| 米国株の為替損益分解(株価要因/為替要因) | ◎ | 同上 |
| 資産総額・資産配分 | ◎ | 同上 |
| 資産推移グラフ(日次/月次/年次) | ○ | **PCでアプリかジョブが動いた日だけ**記録。PCを使わなかった日は、後から取引+過去株価で再計算して補完(日本株は下記の遅延制約あり) |
| NISA枠の使用状況 | ◎ | 取引から計算 |
| 税金の概算 | ◎ | 計算(確定値は証券会社の年間取引報告書) |
| 不動産 | △ | 評価額とローン残高を手入力 → **純資産額(評価額 − ローン残高)を総資産に計上** |
| 未上場株・その他 | △ | 評価額を手入力(日付付きで履歴保存) |
| 投資信託の基準価額 | △ | SBI証券CSVの評価額・基準価額を取り込み、または手入力 |
| 資産目標・将来シミュレーション | ◎ | 計算 |

### B. 株価・為替

| 機能 | 判定 | 実現方法・制約 |
|---|---|---|
| **日本株の現在値(最新終値)** | △ | **J-Quants無料版は12週間遅延のため使えない**。代替: ① SBI証券の「ポートフォリオ」等のCSV(現在値・評価額を含む)を取り込む ② 手入力。出典は「SBI証券CSV(ダウンロード日時)」と表示 |
| 日本株の場中(リアルタイム)株価 | × | 無料の公式APIなし |
| 日本株の過去株価(テクニカル分析用) | ○ | J-Quants無料版: 過去2年分・12週遅延。直近12週分は、CSV取り込みのたびに保存した終値で**自前の株価履歴を蓄積**して補う(取り込まなかった日は欠損) |
| 米国株の現在値 | ○ | Finnhub 無料版のクォート(60回/分目安)。7〜8銘柄なら十分 |
| 米国株の過去株価(日足) | ◎ | Tiingo 無料版(1,000回/日・50回/時・月500銘柄目安)。予備: Alpha Vantage(25回/日) |
| 為替(USD/JPY) | ○ | Frankfurter(欧州中央銀行の参照レート・無料・キー不要)。**1日1回の参照レート**で、日中の値動きは取れない。取引時のレートは取引報告書から手入力 |
| 価格到達アラート(リアルタイム) | × | 取得タイミング(1日数回)でのチェックのみ ○ |

### C. 企業情報・財務

| 機能 | 判定 | 実現方法・制約 |
|---|---|---|
| 日本株の財務(売上・利益・EPS・BPS等) | ○ | J-Quants無料版の財務情報(**遅延の有無・範囲は公式仕様で要確認**)+ EDINET API(有価証券報告書・半期報告書、無料)|
| 日本株の最新決算(決算短信)の数値 | △ | 決算短信PDFを自分でダウンロード → **Claude Code に読ませて数値を抽出 → 確認してから登録**、または手入力 |
| 日本株の会社業績予想 | △ | 同上(決算短信の予想値) |
| 日本株の決算発表予定日 | ○ | J-Quants の決算発表予定日API(全プランで利用可、取得期間はプランで異なる) |
| 米国株の財務 | ◎ | SEC EDGAR(米国証券取引委員会・公式・無料) |
| 米国株のアナリスト予想(予想EPS) | × | 無料で安定して取れる公式ソースなし → 米国株は**実績EPSベース**で分析。予想PERは「不明」と表示 |
| 米国株の決算発表予定日 | ○ | Finnhub 無料版の決算カレンダー |
| PER・PBR・ROE・配当利回り・成長率 | ◎ | **自前計算**(元データの遅延・欠損はそのまま反映し表示) |
| 企業ニュース(米国株) | ○ | Finnhub 無料版のニュース(見出し・URL) |
| 企業ニュース(日本株) | △ | Claude Code のWeb検索で収集(手動実行・出典URL付き) |

### D. 投資分析

| 機能 | 判定 | 実現方法・制約 |
|---|---|---|
| ファンダメンタル指標の算出 | ◎ | Python |
| テクニカル指標(移動平均・RSI・MACD・ATR等) | ○ | 米国株は◎。日本株は自前で蓄積した終値に依存(欠損があると計算不可→「不明」) |
| **ルールベース判定**(AIなしの機械的シグナル) | ◎ | 割安度・トレンド・比率超過などの明示ルールで「買い検討/保有/売り検討/判定不可」を表示 |
| AI投資判断(6段階・理由・スコア・リスク・確信度) | ○ | **Claude Code で手動実行**(`/analyze 7203` のようなコマンド1つ)。自動の定期実行は既定では行わない |
| 買い増し価格・利益確定価格・損切り価格 | ◎ | プログラムが根拠付きで計算(AIは選択と説明のみ) |
| シナリオ別株価(弱気/基本/強気) | ○ | 計算は◎。米国株は予想EPSがないため実績EPSと過去成長率から算出(前提を明示) |
| ポートフォリオのリスク管理 | ◎ | 銘柄・業種・通貨・口座区分の集中度、方針上限との比較、下落シミュレーション |
| 投資判断の履歴・成績検証 | ◎ | DBに保存し、その後の株価と比較 |
| マクロ経済指標(米国) | ◎ | FRED(無料) |
| マクロ経済指標(日本) | ◎ | e-Stat・日本銀行の時系列統計(無料) |
| マクロ解説・投資レポート | ○ | Claude Code で手動生成(`/daily-report`) |

## 0.3 まとめ:無料構成の主な制約

1. **日本株の最新株価は自動取得できない** → SBI証券CSVの取り込み(数クリック)か手入力
2. **日本株の財務・株価の公式無料データは遅延あり** → 最新決算はPDFをClaude Codeで読み取り
3. **米国株の予想EPS(アナリスト予想)は使えない** → 実績ベースで分析
4. **AI分析は自動ではなく、Claude Code でコマンドを実行したときに行う**
5. **アプリはPCが起動しているときだけ動く** → 資産推移は起動時に不足分を自動補完
6. **為替は1日1回の参照レート**

これらを受け入れられれば、要望された資産管理・投資分析の機能は**月額0円で実現できます**。
