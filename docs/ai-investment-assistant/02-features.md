# 2. 必要な機能の一覧

**この章で決めること:** 作る機能の全体と、どの順番で作るか。

優先度の意味:
- **P0** … 第1段階で必須(これがないと使えない)
- **P1** … 早期に追加(実用性が大きく上がる)
- **P2** … 中期(あると便利)
- **P3** … 将来の拡張

「Phase」は 06章ロードマップの段階番号です。

## やらないこと(スコープ外)

- 自動売買・証券会社への発注

- 確定申告書類の作成(概算表示のみ)
- 他人への投資助言(自分専用)
