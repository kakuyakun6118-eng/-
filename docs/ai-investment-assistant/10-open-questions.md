## 10.3 承認をお願いしたいこと

1. **無料構成の制約**(00章 0.3 の6項目)を受け入れること
   - 特に「日本株の現在値は SBI証券CSV の取り込み、または手入力」
2. **技術構成**: Next.js(画面のみ)+ Python FastAPI(計算・データ)+ SQLite、ローカルPCで動作
3. **AI**: Claude Code のカスタムコマンドで手動実行。Claude API は使わない(将来の差し替え口のみ用意)
4. **第1段階の範囲**: Phase 0(開発環境)+ Phase 1(手入力・SBI CSV による資産管理MVP)

承認いただければ、Phase 0 の最初の作業(必要なソフトのインストール手順の説明)から始めます。
