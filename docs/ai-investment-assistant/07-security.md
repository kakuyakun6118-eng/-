# 7. セキュリティ設計(ローカル構成)

**この章で決めること:** 資産データとAPIキーをどう守るか。

ローカルPC構成では、資産データは**自宅PCの中だけ**にあり、外部のクラウドに預けません。
その代わり「PCそのものの安全」と「バックアップ」が重要になります。

---

## 7.1 守るもの

| 対象 | 保存場所 | 対策 |
|---|---|---|
| 資産・取引データ | `data/investment.db`(PC内) | Gitに入れない、PCのディスク暗号化、バックアップ |
| SBI証券のCSV | `data/imports/`(PC内) | Gitに入れない。取り込み後に削除するか選べる |
| APIキー(J-Quants・Tiingo・Finnhub・FRED・EDINET・e-Stat) | Windows資格情報マネージャー(`keyring`)または `.env` | Gitに入れない、画面に送らない |
| 証券会社のID・パスワード | **保存しない** | — |
| AIとの受け渡しファイル | `ai_workspace/`(PC内) | Gitに入れない、一定期間後に自動削除 |

## 7.2 GitHub に絶対に上げないもの
`.gitignore` に最初から登録します。
```
data/
ai_workspace/
.env
*.db
*.csv
```
- GitHub リポジトリは**非公開**(無料)
- GitHub のシークレットスキャン(Push Protection)を有効化 → 万一キーを含めてもpushが止まる
- コミット前に `data/` などが含まれていないか自動チェック(pre-commit)

## 7.3 APIキーの管理
- 第一候補: **Windows資格情報マネージャー**(Python `keyring` で保存・読み出し。ファイルに平文で残らない)
- 代替: `.env` ファイル(Git管理外)。`.env.example` には項目名だけ書く
- キーは Python(backend)だけが使う。Next.js の画面側には一切渡さない
- すべて無料プランのキーなので、漏えいしても金銭被害は基本的にない。それでも漏えいの疑いがあれば再発行
- **SEC EDGAR は User-Agent に連絡先(メールアドレス等)の記載を求めます。** 設定画面で自分で入力していただき、コードやGitには含めません

## 7.4 ネットワーク
| 利用方法 | 設定 | 安全性 |
|---|---|---|
| PCのみ | `127.0.0.1` だけで待ち受け | 最も安全(外から接続不可) |
| 自宅Wi-Fi内のiPhone | 自宅LANからの接続のみ許可 + パスコード | 自宅Wi-Fiのパスワードが前提 |
| 外出先のiPhone | **Tailscale**(自分の端末同士だけをつなぐVPN・無料) + パスコード | インターネットに公開しない |

- **ポート開放・インターネットへの直接公開はしません**
- Python(8000番)は画面(Next.js)からの通信のみ受け付け、外部端末からは直接触れない設定
- パスコードは連続失敗でロック、一定時間操作がなければ再入力

## 7.5 アプリの安全性
- 入力値・CSV・外部APIの返り値・AIの出力はすべて検証(Pydantic / Zod)
- DB操作はパラメータ化(SQLインジェクション対策)
- CSVは中身をプレビュー・検証してから取り込み(想定外の形式は拒否)
- 依存パッケージの脆弱性チェック(GitHub Dependabot・無料)

## 7.6 AI利用時の注意
- Claude Code に渡す入力パッケージには、**氏名・口座番号・証券会社のログイン情報を含めない**
- ポートフォリオ情報は比率中心(必要な場合のみ金額)
- ニュース等の外部テキストに含まれる指示には従わないようコマンドで指示(プロンプトインジェクション対策)
- AIの出力は必ず検証してから保存

## 7.7 バックアップ
| 方法 | 費用 | 備考 |
|---|---|---|
| 外付けUSB/HDDへ自動コピー(推奨) | 0円(既存機器) | 1日1回、世代管理(30日分) |
| OneDrive 等のクラウド | 無料枠 | 資産データを預けることになるため、**パスワード付き暗号化ZIP**にしてから保存(任意) |
| CSVエクスポート | 0円 | 取引履歴を人が読める形でも保管 |

SQLite は1ファイルなので、コピーするだけで完全なバックアップになります(コピー時はアプリ側で安全な方法を使う)。

## 7.8 PC側の対策
- Windows のログインパスワード / PIN、画面ロック
- BitLocker 等のディスク暗号化(Windows のエディションによる)
- Windows Update とウイルス対策を有効に
