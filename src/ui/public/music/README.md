# 背景音楽の置き方

このフォルダに **`theme.mp3`** を置くと、ゲーム中に繰り返し再生される。
**ファイルを置かなければ音楽は鳴らず、音のボタンも出ない。** 無くても遊べる。

```
src/ui/public/music/theme.mp3
```

差し替えるときはこのファイルを置き換えるだけでよい。
パスは `src/ui/music.ts` の `TRACK_URL` に定義してある。

## 仕様

| 項目 | 値 |
|---|---|
| ファイル名 | `theme.mp3`（固定） |
| 形式 | MP3（Safari・Chrome・Firefox のいずれでも再生できる） |
| 長さ | 2〜5分程度。末尾から先頭へ繰り返し再生される |
| 音量 | コード側で 0.4 に落としている（`DEFAULT_VOLUME`） |

繰り返し再生されるので、**曲の終わりと始まりがつながる音源**のほうがよい。
フェードアウトで終わる曲は切れ目が目立つ。

## 再生の挙動

- ブラウザは操作なしの自動再生を許さないため、**難易度を選んだ時点**で鳴り始める
- 画面右上のボタンでいつでも止められる。選択は `localStorage` に残るので、
  一度止めれば次回以降も止まったままになる

## 権利について

**音源はこのリポジトリに含めない。** 権利を持っている音源、または
商用利用が許諾されている音源を各自で置くこと。

市販曲（例: Two Steps From Hell の楽曲）は権利者の許諾なしに
同梱・配布できない。個人で手元で遊ぶ場合でも、リポジトリに
コミットして共有することはできない。

`.gitignore` で `*.mp3` を除外してあるので、置いても誤ってコミットされない。
