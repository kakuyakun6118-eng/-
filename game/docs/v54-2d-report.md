## 3. 8区画の表示

- 8つの区画があります:皇帝の寝殿・皇后の宮殿・妃たちの居所・女官の詰所・後宮の庭園・浴殿・宴会場・回廊。
- 左の「後宮の地図」から移ります。場所の名前の横に、いまそこにいる人数が出ます。
- 移ると背景が替わり、その区画に、その時刻にいる人だけが出ます(いない人は出しません)。
- 時刻の光:朝もや・昼・夕焼け・夜の灯火(ゆらぐ)を、背景に重ねます。
  - 朝・夕の絵が無ければ、昼の絵にこの色を重ねます。
  - 夜の絵が無ければ、昼の絵に夜の色を重ねます。

## 4. 肖像画の登録の仕方

- **配役は22人分です。**
  - 物語の6人(A1〜A6):物語の役を持つ人には、必ずその役の専用の絵を使います。
  - 一般の人(N01〜N04、L01〜L10、S01、D01):年齢と身分の近い絵を、重ならないように割り当てます。
- 割り当ては人物ごとにセーブに残るので、同じ人の顔が途中で変わることはありません。
- **取り込み:** 届いた絵は `tools/palace2d/import_image.py` で取り込みます。
  - 透明な余白を切ります。
  - WebP の大きい版(高さ1400)と小さい版(スマートフォン用、高さ800)を作ります。
  - `public/palace2d/` に置くと、ビルドのたびに目録ができます。
- **読み込み:** 画像はゲームに埋め込まず、別のファイルとして使う時だけ読み込みます。読み込んだ画像は、新しく使った順に24枚まで手元に残し、古いものは手放します。
- **画像が無いとき:** 仮の絵(衣の色の影絵)を出します。仮の絵には、名前と、登録が要る ID(「A5・微笑み」など)を書いています。
- **確かめる所:** 「絵の登録」の欄で、ID ごとの登録済みの表情の数と、その絵を使っている人が分かります。

## 6. 表情差分

- 8種類あります:通常・微笑み・喜び・悲しみ・怒り・困惑・驚き・照れ。
- 表情は、次のことで変わります。
  - 会話・贈り物・誘い
  - 告白・妃・皇后の申し出(受けたか、断ったか)
  - 物語の場面と選んだ結果
  - 宮廷の事件の結果
  - ふだんは、気分・嫉妬・恋心
- 大きな肖像は2枚を重ねてあり、表情が変わるとなめらかに入れ替えます。
- 足りない表情は、近い表情で代わりにします。
  - 喜び・照れ → 微笑み → 通常
  - そのほか → 通常
- 試験用に書き出した絵で、正しく切り替わることを確かめました(試験40 T5)。

## 7. 個別の物語

- 6人の5段階の物語・分岐・結末・約束・記憶は、そのまま残しています(試験37 S1〜S5)。
- 物語の場面では、相手を大きく出し、場面の表情にします。選んだ結果の表情にも替えます。
- 結末になったとき、その物語の一枚絵があれば出します(押すと閉じます。試験40 T6)。
- 結末のあとの便り(後日談)は、これまでどおり報告に届きます。

## 8. 恋愛・婚姻・皇位継承とのつながり

## 12. メモリと描画の重さ

- 宮殿では WebGL で描きません。描画の重さは、ほぼ無くなりました。
- 3Dの頭の素(3.6MB)はビルドから外しました。
- 20年の長期試験:3Dのときは約110秒でしたが、2Dでは約60秒です(ソフトウェア描画の環境)。
- メモリ(宮殿で40年進める、ごみ集めのあと):

  | 時点 | 2D(今回) | 3D(Version 54 第1工程のあと) |
  |---|---|---|
  | 開始 | 169MB | 178MB |
  | 20年 | 180MB | 190MB |
  | 40年 | 181MB | 192MB |

- 20年でメモリが増えていた原因は、オートセーブの書き込み待ちがたまることでした。直したあとは、2Dでも3Dでも増え続けません。
- 2Dの画面のメモリと画像の数は、`screen.stats()` で測れます。
