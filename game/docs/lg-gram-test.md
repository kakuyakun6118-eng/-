## 2. FPS(画面のなめらかさ)の測定

メニュー → 設定 → 「画面のなめらかさ(FPS)を表示する」にチェック。左上に「FPS ○○・最長フレーム ○○ms」が出ます。
(戦略マップは、動きのないときは描き直しを省くので、何も操作しないときの数字は参考です。)

| 番号 | 場面 | 操作 | 記入(FPS / 最長フレーム) |
|---|---|---|---|
| 2-1 | 戦略マップ・静止 | 何もしない(10秒) | / |
| 2-2 | 戦略マップ・移動 | 中国本土を2本指で動かし続ける(10秒) | / |
| 2-3 | 戦略マップ・西域 | 敦煌より西へ移動して動かす(10秒) | / |
| 2-4 | 早送り | 速度を最速にして30秒 | / |
| 2-5 | 3D会戦・開始直後 | 会戦を始めて10秒 | / |
| 2-6 | 3D会戦・乱戦 | 両軍がぶつかっているとき10秒 | / |
| 2-7 | 3D会戦・攻城戦 | 城を攻めているとき10秒 | / |

目安:戦略マップで 30 FPS 以上、3D会戦で 20 FPS 以上なら、ふつうに遊べる。最長フレームが 500ms を超える場面があれば、場面を書き留める。
