# 『五胡乱華』LG gram 実機テスト手順書(Version 40)

対象の機種:LG gram 2in1(画面 1920×1200・メモリ 16GB)。キーボードとタッチパッド、タッチ操作とペンの両方で確かめます。
この手順書の項目は、**プレイヤーが実機で確かめるまで「完了」にはしません**。結果の欄に ○・×・気づいたことを書いてください。

| 0-5 | 起動から地図が出るまでの秒数を計る | 目安:15秒以内 | |

| 番号 | 手順 | 期待する結果 | 結果 |

| 1-1 | 右側のボタン(メニュー・人物・外交・名品・財政・皇室・年表・歴史イベント・交易路・補給)を上から順に見る | 重ならず、文字が切れず、すべて押せる | |

## 5. 3D会戦の手動操作

| 番号 | 手順 | 期待する結果 | 結果 |
|---|---|---|---|
| 5-1 | 会戦の知らせから「会戦準備へ」→「会戦開始」 | 3Dの戦場に切り替わる(待ち時間を記録) | |
| 5-2 | 自軍の部隊をクリック/タップで選ぶ | 部隊の情報と命令の釦が出る | |
| 5-3 | 地面をクリック/タップ → 部隊が動く。敵をクリック/タップ → 攻撃する | 思った所へ動き、攻撃する | |
| 5-4 | 待機・前進・後退・追撃・陣形・向き(↶↷)を順に押す | それぞれ効く | |
| 5-5 | 複数選択・全選択・全軍前進 | 複数の部隊が同時に動く | |
| 5-6 | 視点の回転(⟲⟳)・全景・近景・追従 | 見やすく切り替わる | |
| 5-7 | 一時停止・速度 | 止まる・速くなる | |
| 5-8 | 会戦中のなめらかさ(兵が多い会戦で) | 目安:ひどいカクつきがない(気になれば秒間の様子を書く) | |
| 5-9 | 全軍撤退(確認が出る)→ 結果の画面 → 戦略マップへ戻る | 結果が地図に反映される | |
