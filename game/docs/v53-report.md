## 3. 人物の形と衣装

- **形**:人物は、骨組みのある体として作り直しました。
  - 腰・胴・頭・左右の腕・裳(スカート)・両足が、別々に動きます。
  - 体格は、人ごとに少しずつ違います。
- **衣**:重ね着の衣と縁取り、帯、袖口、裳の裾。衣には模様の絵が付いています。
- **顔と髪**:
  - 顔立ちは3種類です。
  - 顔は、表情ごとの絵を貼っています。
  - 髪型は、人によって違います。
- **位の飾り**:
  - 皇后:歩揺の冠
  - 妃:かんざしと垂れ飾り
  - 女官:かんざし
  - 皇帝:冠
- **披帛と持ち物**:披帛(肩の薄布)を掛けます。書・琴・椀を持たせられます。
- **建物と家具**:
  - 建物:反りのある瓦屋根、鴟尾、隅棟、斗栱、格子の窓と戸、基壇・階段・欄干。
  - 家具は、区画ごとに置いています。寝台・屏風・櫃・香炉・器・敷物・書棚・機・鏡・琴・鐘・太鼓・宴の膳・灯火。
  - 季節で、木の色・蓮・雪が変わります。浴殿には湯気が出ます。
  - 空は時刻で色が変わり、遠くに山があります。

## 4. 表情と動き

- **表情(8つ)**:普通・微笑み・喜び・悲しみ・怒り・困惑・驚き・照れ。
  - 会話・贈り物・物語の選択の結果で、表情が決まります。
  - ふだんは、気分・嫉妬・恋心から表情を決めます。
  - 3Dの顔と、交流の欄の似顔は、同じ表情になります(試験 G2)。
- **動き**:歩く・止まる・座る(正座へ移る)・立つ・拝礼(揖)・身ぶり(話す)・向きを変える・散策・読書・楽器・食事・宴。
  - 試験 G1 では、骨組みの角度が実際に変わることを確かめました。
    - 歩く:足が 0.17、腕が 0.50 振れる
    - 座る:腰が 0.5 下がる
    - 拝礼:上体が 0.55 傾く
    - 話す:腕が 0.49 動く
  - 止まった人形を動かしているだけではありません。
- **居場所**:人物は、時刻の予定の区画まで、経路を探して歩きます(瞬間移動はしません)。
  - あとから来た人は、区画の入口から入ってきます。
  - 皇帝が近づくと、拝礼して皇帝のほうを向きます。
- **直した不具合**:見えていない人物の動きを間引いたとき、遅れた時間を足していませんでした。そのため歩みが4分の1になっていました。これを直しました。
- **光**:朝・昼・夕・夜で、日の向き・色・空・灯火が変わります。
- **環境音(合成音)**:風・水・鳥・足音・宮の生活音(拍子木・鈴)・宴の楽・夜の虫。
  - 場所・時刻・季節で、鳴る音が変わります(試験 G4)。
  - **音声ファイルは使っていません。録音した音は入っていません。**

## 6. 6人の物語の分かれ方と結末

- 各物語は5段階です。
- 各段階に進む条件は、次のようなものの組み合わせです。
  - 親密・信頼・希望
  - それまでの選択
  - 派閥、国の様子(出身の都市が戦場かどうかなど)
  - 季節、時刻
- 選んだ道によって、結末が分かれます。試験 S3 では、6人とも二つの道で結末が違うことを確かめました。

| 物語 | 道A の結末 | 道B の結末 | ほかの結末 |
|---|---|---|---|
| 筆の跡 | 想いの通う間柄 | 信頼で結ばれた仲間 | 女史として学問の道へ・宮を出て自分の道へ |
| 階 | 尚宮として宮を束ねる | 派閥を離れ自分の道へ | — |
| 故郷の便り | 都で家族と暮らす | 心を許した友 | 故郷へ帰り家族のもとへ |
| 主への忠 | 主に仕え続ける忠臣 | 皇帝の腹心 | — |
| 宮の灯 | 皇后として | 心の離れた間柄 | 後継の母として・穏やかな日々 |
| 籠の外 | 旅立つ医女 | 宮の医女 | — |

恋愛の結末は、相手が成人で、本人が同意したときだけです。断られたら、30日は同じ申し出をしません。

## 7. 記憶と約束の仕組み

- **記憶**:人物ごとに、重要な出来事を残します。
  - 残すもの:贈り物、約束、物語、事件。
  - 上限は1人30件です。
  - 会話の中で、記憶が言葉に出ます。
- **会話の記録**:ふだんの会話は、全体で50件までにしています。
- **約束**:話の中で皇帝が約束をすると、記録が残ります。
  - **果たす行動をして、日数がたつまで、果たした扱いになりません。**
  - 果たす行動の例:使者を送る(金60・10日)、書を届ける、調べさせる、医者を送る。
  - 期限を過ぎると、約束は「破られた」になります。その人の信頼が下がり、記憶にも残ります(試験 S4)。
- セーブ・ロードしても、段階・選択・約束・記憶は残ります(試験 S5)。

## 8. 人間関係と派閥

- **関係の種類**:親しい・信頼・張り合い・嫉妬・派閥・一族・主従(仕える主と、仕えてくれる人)。
  - 信頼は、好き嫌いとは別の数として持ちます。
  - 親しい間柄が続くと、信頼は少しずつ育ちます。仲の悪い間柄では、少しずつ失われます。
  - 昼に同じ区画で過ごす人どうしは、気が合えば親しくなり、合わなければ溝が深まります。
- **寵愛への反応**は、性格と関係で違います(試験 C2)。全員が嫉妬するわけではありません。

  | 立場・性格 | 反応 |
  |---|---|
  | 一族、仕える人 | 喜ぶ |
  | 誇り高い人 | 妬み、張り合う |
  | 一途な人 | 妬む |
  | 内気な人 | 寂しがる |
  | 穏やかな人、明るい人 | 親しい相手なら喜ぶ |
  | 賢い人 | 同じ派閥なら近づき、違えば張り合う |
  | 想いのない人 | たいてい気にしない。ただし誇り高い人・出世を望む人は、身分を妬む |

- **皇后と妃の立場**は、権威の値で表します。権威は次のことで決まります。
  - 位
  - 子の数
  - 後継者の母かどうか
  - 一族(同じ姓・同じ民族の臣下)の人数と官職
  - 寵愛
  - 廃されたかどうか
  - 人物の欄に「立場」「一族」「仕える主」「関係」が出ます。
- **派閥**:皇后・妃を頭に、気持ちの近い人が集まります。

## 9. 宮廷の事件(9種類)

- 事件は、乱数だけでは起きません。**条件がそろったときだけ**起き得ます。
  - 条件がそろう前は、確率を省いても起きないことを確かめました(試験 C4)。
- 事件には、起きたわけ・関わる人・選択肢・期限(10日)があります。
- 選んだ結果は、後宮の気持ちと国の数字に反映します(試験 C5)。
- 期限を過ぎると、「放っておいた結果」になります。

| 事件 | 起きる条件 | 選択肢 | 国への反映 |
|---|---|---|---|
| 女官どうしの対立 | 二人の気持ちが互いに -30 / -20 以下 | 仲を取り持つ・片方を認める・勤め先を分ける | 放っておくと安定度 -1 |
| 皇后と妃の対立 | 寵愛の差 15 以上、または皇后の嫉妬 | 皇后を認める・妃をかばう・宴で和解(金200) | 安定度 ±、一族の忠誠 |
| 噂 | 嫉妬 55 以上で、嫌う相手がいる | 調べる(金30)・禁じる・取り合わない | 安定度 |
| 贈り物の騒ぎ | 5日以内の贈り物と、妬む人 | 贈り直す(金50)・調べる・収める | 国庫 |
| 外戚の任官 | 寵愛を受ける妃に、官職のない一族がいる | 官職に就ける・金品・認めない | 官職、忠誠、安定度 -3、重臣の忠誠 -4 |
| 後継の教育 | 後継者が 6〜15歳で、母が後宮にいる | 儒学・武芸・両方(金80) | 後継者の知力・政治・武力・統率 |
| 密告 | 不満のある人(評価 35 未満)と、その人を嫌う人 | 信じる・自ら確かめる・たしなめる | 信頼 |
| 重臣の諫言 | 後宮に 45日以上、または30日の出費が 金800 以上 | 聞き入れる・褒める(金50)・退ける | 重臣の忠誠 ±、安定度 ± |
| 皇后の廃立 | 皇后の立場が弱く、妃と争いが続いている | 廃する・支える・決めない | 安定度 -10(後継者の母なら、さらに -5)、一族の忠誠 -20 |

**皇后の廃立**
- 変えるのは、婚姻の種類(正室→側室)と、後宮での呼び名(廃后)だけです。
- 人物・婚姻・子との縁・家系図は消しません。
- セーブ・ロード後も、同じ状態です。
- 新しい皇后は、本人の同意があれば立てられます。もとの皇后は、妃として残ります(試験 C6)。
- 同じ種類の事件は、時を置いてから起きます。
  - 諫言:半年
  - 廃立:1年
  - 女官の対立・密告:120日(同じ二人なら1年)
  - そのほか:60日

## 10. 政治のAIとのつながり

- 宮殿にいるあいだ、自国は戦略AI(重臣)が動かします。
- 事件の結果は、安定度・忠誠・国庫・官職・後継者の能力に入ります。戦略AIは、これらの数字を見て判断します。
- **後宮の揺れ**(0〜100)を計算し、戦略AIが読みます。
  - 揺れのもと:開いている事件、半年以内の廃立、子のいる妃どうしの争い、後宮の気分。
  - 揺れが 60 以上になると、戦略AIは外征を控えて内政を固めます。理由には「後宮の争いで宮廷が揺れている」と出ます。
  - 揺れが収まると、ふだんの判断に戻ります(試験 C7)。

**第3工程(建物・家具・人物の作り直し)で、ソフトウェア描画では遅くなりました。**
- 原因を切り分けました。
  - 一コマの JavaScript は 5ms 未満で、ここは原因ではありません。
  - 模様の絵を貼った大きな面(地面・床・屋根)を塗る手間が大きく、模様の絵をやめると約2コマ速くなりました。
  - 増えた形(三角形が2〜4倍)を塗る手間も、大きくなりました。
- 次の軽くする手立てを入れました。ただし、ソフトウェア描画での効果は小さいものでした。
  - 空を最後に描く。
  - 室内の家具の影をなくす。
  - 室内を描く距離を短くする。
  - まとめ描きの範囲を広げる。
  - 低・中の画質では、模様の絵の拡大縮小を軽い方式にする。
- GPU のある実機では、塗る手間はずっと軽いはずです。**ただし、確かめていません。**
- 実機で遅いときは、画質「低」を使ってください。iPhone では、はじめから「低」になります。
