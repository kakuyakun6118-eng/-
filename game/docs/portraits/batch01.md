# 肖像 第1回(主要人物)の制作指示

画風・時代考証・描き分けを確かめるための最初の組。保存名は `public/portraits/<ファイル名>`、256×256 の WebP。

## 全員に共通の指定

写実的で重厚な歴史人物の肖像画。油彩のような質感、落ち着いた光、暗い無地の背景。胸から上の構図で、顔がはっきり見える。正方形。4世紀の中国(西晋〜東晋・五胡十六国)の装い。明・清の官服や官帽、満洲式の辮髪、近世以降の甲冑、日本式の兜、西洋の板金鎧、現代の小物は描かない。文字・印・枠・透かしは入れない。ほかの人物と同じ顔にしない。

- 装い:革や鉄の小札鎧、毛皮の縁取りのある外套、革の帯。
- 顔立ち(創作設定):細面、太く一文字の眉、大きく丸い目、口髭と短い顎髭、思慮深く落ち着いた表情、人を引きつける堂々とした佇まい
