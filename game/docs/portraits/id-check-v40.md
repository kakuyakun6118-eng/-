## 照合の方法

1. 一覧画像の名札(番号と名前)と、`missing-portraits.xlsx` の番号・名前・人物IDを照らし合わせた。名札のない回は、制作リストの順番(左上→右上→左下→右下)で当て、
   僧侶(鳩摩羅什)・子ども(石世・張耀霊)・若い皇帝(懐帝・愍帝・康帝)など見た目の分かる人物で、並びがずれていないかを確かめた。
2. 同じ名前の人(段氏・李氏・劉氏など)は、制作リストの位置で人物IDを決めた。
3. 王猛・謝安(若い方)は、届いた新しい絵があったが、前から登録済みのため差し替えていない。
4. 2回目に届いた同じ4人(苻崇・慕容麟・視羆・慕容盛)の別案は `docs/portraits/alternates/` に保管。

## 一括取り込み

`tools/sheet_import.py` で、一覧画像(2×2・3×1 など)から切り出して取り込める。
- 当てるIDは `--ids`(並び順に書く。「-」で飛ばす)か `--list missing-portraits.xlsx`(足りない順に当てる)。
- 台帳にないIDは取り込まない。すでにある画像は、`--overwrite` を付けない限り上書きしない。`--dry` で当て方だけを確かめられる。
- 名品の絵も `--kind treasure` で同じように取り込める(public/treasures/、384×384)。
