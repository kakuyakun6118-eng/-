# Version 42 の報告

この文書の「確かめた」は、すべて**この開発環境の自動テスト・試行(Playwright とソフトウェア描画の Chromium)**での結果です。
**LG gram と iPhone の実機では、まだ確かめていません**(手順書:docs/v42-device-test.md)。

あわせて、iPhone で日付の帯・知らせの文章と右の釦の列(人物・外交など)が重なる問題を直しました。右の釦の列と題字の位置を測り、そのあいだの空きに置くようにしたので、文字の大きさの設定やブラウザの拡大でも重なりません(844×390・932×430・667×375・390×844・1920×1200・拡大1.25倍で確認)。

## 1. 西晋が金城を攻めた原因と、直した結果

### 原因(300年開始で、出兵の判断の記録から特定)

313年2月、南の「建鄴の軍」が、楽浪を足場に新羅の金城を攻めていました。

| 項目 | 値 |
|---|---|
| 出発の都市(足場) | 楽浪(軍団そのものは建鄴の軍) |
| 目標 | 金城(新羅) |
| 実際の道のり | **3,078km**(直線1,017km) |
| 必要な兵糧の見積もり | 75日分(手持ち90日分) |
| 攻める価値 | 173 |
| 方針 | 統一志向 |
| ほかの候補 | なし(その時点で戦争中の相手が新羅だけだった) |

原因は4つ重なっていました。

1. 遠さを、軍団からではなく、**自国のいちばん近い都市(朝鮮半島の飛び地・楽浪)から**測っていた。
2. 目標の評価に、**実際の道のり**を使わず、直線の距離で日数を見積もっていた。
3. 西晋が、本拠から遠い飛び地のそばの小国(新羅)に**宣戦していた**。
4. 候補が1つしかないと、比べる相手がないまま選ばれた。

### 直したこと

- **戦略的な関心**(0〜1)を、国ごと・目標ごとに計算するようにしました。
  - 決め手:国の中心(都市の格で重みを付けた重心。首都は重く)からの距離、前線からの距離、もとの自国の地か、国内の安定、本拠の近くで戦争が続いているか、歴史のモード(史実重視ほど本拠から遠い所への関心が薄い)。
  - 関心の薄い目標は、勝算が3倍以上**かつ**価値が200以上のときだけ選びます(遠いからといって一律には禁じません)。
  - 関心が0.3未満の国には宣戦しません。
- 上位3つの候補を、**軍団からの実際の経路**で見直すようにしました。遠回り(直線の2.2倍超)や、道のりが行動範囲の2.5倍(統一の方針は3倍)を超える目標は選びません。日数も経路の長さで見積もり直します。
- **出兵の判断の記録**を残すようにしました。出兵の年月・出発都市・目標・道のり(経路と直線)・日数・必要な兵糧と手持ち・価値・勝算・方針・首都のそばの守りの軍団の数・ほかの候補とその点数。

### 結果(300年開始・15年、新羅を操作)

- 西晋の朝鮮半島への出兵は**0回**でした。道のり2,000km超の出兵も0回で、新羅は315年まで残りました(テスト32-1)。
- 関心の値の例:西晋にとって洛陽は1.0、金城は0.16です。

## 2. 304年開始の漢の存続

### 調べて分かったこと

- 漢は、開始時の国庫が金102・兵糧48しかありません。18,000の軍を保てず、早くから弱っていきます。
- 漢は西晋の勢力の真ん中にあり、すぐそばに西晋の大軍(約7万)がいます。
- 変更前の版で漢が残っていたのは、AIの不合理さのおかげでした。西晋の張方軍が漢軍を追いかけ回すだけで、守りの薄い離石を攻めなかったためです。

### 直したこと

**AIの判断**

- 迎撃・援護の行軍が、行き先のそばにある敵の都市の攻城になっていた不具合を直しました(迎撃のつもりが、敵の首都の攻城になっていた)。
- 迎撃は、相手が自国の都市から離れて自分の領内へ退いたら、そこで終えるようにしました(撃退)。
- **主な敵に力を集める**判断を足しました。戦争中の相手に自国の半分以上の力を持つ国があれば(史実重視のモードでは2割以上)、その国を攻めることを重んじ、弱い周辺の国への攻撃は控えます(史実重視では大きく控える)。八王の乱の最中の晋が、周りの小勢力に手を回せなかったことを、判断の重みとして表したものです。
- 首都に敵が迫っているあいだは、首都を守れる唯一の軍団を遠征に出しません。
- 周りの敵が自国の2.5倍(史実重視2倍・自由歴史3.5倍)を超えて強いあいだは、本拠から150km超の所へ攻めに出ません。

**首都の防衛**

- 3日ごとに首都を見張るようにしました。
  - 首都へ向かう敵・そばの敵と、300km以内にいる戦争相手の軍団(重みを下げて)から、首都の危うさを計ります。
  - 危うければ、次のことを考えます:首都での募兵、近くの軍団の呼び戻し(野戦で勝てるときだけ迎え撃つ)、籠城(勝てない軍団は城に入って守備兵になる)、君主の退避、停戦の申し入れ。
- **君主の退避**は瞬間移動ではありません。道に沿って1日およそ35kmずつ移ります。
  - 敵の軍団のそば(25km以内)を通ると、1日ごとに4割の見込みで捕まります。
  - 行き先を失えば、別の自国の都市へ向け直します。
  - 退避先は、敵から離れ、道が敵のそば(30km以内)を通らない都市の中から、格の高い順に選びます。
  - 首都の太守を兼ねていれば、その任を離れます。
- **遷都**のときも、君主は道に沿って移ります(瞬間移動しません)。君主が退避の途中なら、その行き先を新しい都にします。
- 新しく建った国(独立・建国・後継国家)の国庫は、元の国から分けた分が収入の3か月分に足りなければ、そこまで補います(シナリオ開始時と同じ決まり)。

## 4. 攻城戦の救援軍(手動と自動の比べ)

手動の3Dの攻城戦と、AIどうしの自動の攻城戦で、同じ決まり(src/sim/relief.ts)を使うようにしました。

| 決まり | 手動(3D) | 自動 |
|---|---|---|
| 到着の時刻 | 戦略マップの経路の手間(km×地形の通りにくさ)× 1.5秒(最短20秒・最長300秒) | 同じ値を、戦いの日数に直して使う(20秒 = 1日) |
| 着く前の戦力 | 戦場にいない(描かれず、戦わない) | 守りの強さに数えない |
| 途中から加わる | 着いた時刻から戦う | 着いた日から守りに加え、残りの日数を強さの比で延ばす |
| 着く前に決着 | 戦わず、兵も失わない | 加わらず、兵も失わない |
| 妨害 | 救援の道が、攻め手の別の軍団の近く(20km以内)を通るなら、救援に加わらない(知らせが出る) | 同じ |
| 士気 | 軍団の士気 × 連携の度合い。兵糧が尽きていれば -15、疲労が50を超えた分も下がる | 同じ |
| 結果 | 部隊ごとの残りの兵を、その軍団に書き戻す | 加わった軍は守りと同じ割合で失い(落城なら半分)、その軍団に書き戻す |

**試行(テスト32-2)**

| 場面 | 結果 |
|---|---|
| (a) 遠い救援軍(到着195秒=9.75日)と、強い攻め手(5日で落城) | 救援軍は加わらず、兵も変わらない |
| (b) すぐそばの救援軍(38秒=1.9日)、包囲9日 | 途中から加わり、2,100人を失った |
| (c) 救援の道に、攻め手の別の軍団がいる | 「道を阻まれました」となり、救援に加わらない |
| (d) 救援軍2つ | 35秒と178秒に別々に着く。手動の3Dの部隊も同じ35秒・178秒に現れる |

**AIどうしの攻城戦の包囲の日数**

AIどうしの攻城戦は、戦略マップの上で包囲の日数(見積もり、3〜60日)をかけて決着するようにしました。そのあいだに、攻められた側が増兵・救援・退避を考えられます。また、包囲している軍団は、ほかの軍団に襲われることがあります。

## 5. 3Dの地形

**野戦**

- **道**:戦略マップの道すじを、戦場に「踏み固められた土の帯」として描きます。道の上は1.15倍の速さです。
- **浅瀬(渡し場)**:戦場に入れる浅瀬は3種類です。
  - 史料の渡し(crossings.json の孟津・蒲津など)が戦場にあれば、その地点。
  - 道が川を渡る所(3か所まで)。
  - 部隊を動かせる範囲に深い川があって渡れる所がなければ、川幅のいちばん狭い所(2か所まで)。

  浅瀬は、川幅のいちばん狭い向きに、岸から岸まで帯で浅くし、両岸に杭を立てます。深い水は渡れず、浅瀬は0.7倍の速さで渡れます。
- **地表の種類ごとの効果**:湿地は0.75倍(騎兵0.6倍)、低木の茂みは0.92倍の速さです。
- **戦闘への影響**:
  - 水の中・湿地からの突撃は勢いが半分になる。
  - 渡河中の敵への突撃は1.3倍。
  - 岸から渡河中の敵を討つと1.2倍。
  - 渡河中の的への射撃は1.15倍、低木の茂みの的は0.85倍。
  - Version 41 から:林の中の的は0.7倍、見上げて射るのは0.85倍。
- **景観の設定**を2つ足しました。どちらも見た目の設定で、新しい地域ではありません。
  - 「西域のオアシスと砂漠」(東経97度より西)
  - 「江南の水郷」(北緯32.5度より南)

## 7. 反乱・独立

- **調べて分かったこと**:AIの君主が、毎月、忠誠が55未満の人に褒美を与えていました。そのため、領土の広さや遠い任地のような根の深い不満まで、毎回お金で消えていました。300年からの通しで西晋が90を超える都市を持っても、太守と指揮官の忠誠はいちばん低くて55。50年で反乱0件でした。
- **直したこと**:
  - 同じ人への褒美は、1年のうちに重ねるほど効き目が薄れるようにしました(直近1年の回数 n に対して 1/(1+n))。
  - 都市が30を超える国では、役目についている人すべての忠誠を、領土の広さに応じて最大8まで下げます。「都から遠い任地」の距離は、800kmから500kmに縮めました。
  - 新しく従えた地の任地では、さらに3下げます。
- **結果**:
  - 300年からの30年で、西晋の太守・指揮官の忠誠は46〜57に下がり(前は55〜100)、反乱が1件起きました。
  - 同じ条件で5回×24か月を試すテスト(30-4)の、安定した国と危機の重なった国の差は、引き続き確かめています。
