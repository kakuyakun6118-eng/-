## 6. 原因

### 確認された事実

1. **47年間の「外交」方針(戦わない・軍を増やさない)**
   - 325年から372年まで、楚は一度も宣戦せず、野戦軍は49,000〜52,000人のまま、4軍団から増えませんでした。都市(30)・人口(1,189,367)も、47年間まったく変わりませんでした。
   - 原因は戦略AIの性格の計算です。表にない人物の性格は能力値から決まり、「攻撃性 =(武力+統率−知力−政治)÷120」「外交 =(魅力+政治−120)÷80」です。
     - 劉皓は、攻撃性がほぼ0、外交は上限です。そのため戦争のないときは、方針が必ず「外交で勢力を保つ」になり、この方針では宣戦しません。
     - 劉雅(95がそろう)も同じでした。
   - 能力が高く、まんべんなく強い君主ほど、AIが平和主義になる作りでした。
2. **漢の専用AIは劉皓本人だけ**
   - 漢の都を狙う・天下統一のため宣戦する専用のAI(strategy.ts)は、「君主が劉皓(vh_liu_hao)であること」が条件でした。劉皓の死で止まります。
   - さらに、洛陽と長安の両方を持っていないと、統一の宣戦は働きません。
3. **人材の枯渇**
   - 建国の家臣20人は年齢が近く、340〜359年にまとめて老衰で亡くなりました。
   - 登用で補えず、武将は51人から7人に減りました(登用+40の炎漢正統も、劉皓の死で消えた)。
4. **後継**
   - Version 64 には劉皓の子がいませんでした。架空の劉雅が継ぎ、その死後は家臣の李離が君主になりました。
   - この家臣の後継は、Version 65 で直した不具合と同じです。
5. **東海王の侵攻**:372年9月に東海王 司馬越が攻め込みました(373年の兵力の目安 192,042対、楚の野戦軍55,368+守備93,451)。
   - 楚は守勢のまま、372〜378年に都市を30から16に減らしました。
   - 377年8月21日には、首都の襄陽を西晋に奪われました。
6. **滅亡**:382年1月1日、楚は滅びました。主に滅ぼしたのは東海王 司馬越で、首都の襄陽を奪ったのは西晋です。残った西の都市は、後継の国(楚・氾瑗)や西域の国々に分かれました。
7. **長期テストの作りの問題**
   - プレイヤーの国(新羅)が滅ぶと、テストは「一覧の最初の生きている国」を新しいプレイヤーにします。一覧の最初は楚です。
   - そのため、9回の再現のうち6回で、317年6月から楚がプレイヤーの国(誰も操作しない)になり、AIが動かなくなりました(都市59のまま80年止まる)。
   - Version 65 のテスト47・自分用の道具は楚を除いていましたが、テスト45は除いていません。
8. **戦えない戦争で止まる**(公平な条件の再現 f1〜f3)
   - 楚を除いて進めると、漢は78都市まで広がりました。そのあと、海の向こうや遠くの1都市の国(新羅・成)との「届かない戦争」が終わらず、80年止まりました。
   - 宣戦の枠(戦争1つまで)と、膠着の和平(自国が弱いときだけ)のため、和平も新しい宣戦もできませんでした。

### 推定される原因

- 漢が47年動かなかったあいだに、東海王の兵力は大きく増えたと考えられます。373年には楚の約1.3倍でした。平和のあいだの東海王の兵力の推移は、記録していません。
- 金は189,000あったのに、募兵に使われていません。「外交」の方針では募兵の予算を回さないためと推定されます。
- 人口が47年間まったく増えないのは、人口の増える仕組みがないためと推定されます。

- 東海王がなぜ372年に宣戦したか(相手のAIの判断の記録は取っていません)。
- 劉雅の両親と、379年の劉雅の死因。
- テスト45の、報告に書いた1回そのものの細部(再現できないため)。

## 7. まとめ:根本の原因

漢が滅んだのは、皇位継承だけが原因ではありません。

1. 能力の高い君主をAIが「外交型」と判断し、47年間、拡大も軍備もしなかった。
2. 漢の専用AIと8つの固有能力が劉皓個人に結びついていて、劉皓の死とともに国の力が一度に失われた。
3. 年齢の近い家臣団が一斉に老い、人材が補われなかった。
4. 劉氏の後継が弱く、最後は家臣が継いだ。

この4つが重なり、軍備を増やした東海王と西晋に、10年で滅ぼされました。テストの作り(楚が「プレイヤーの国」になる・届かない戦争)も、結果を大きく歪めていました。
