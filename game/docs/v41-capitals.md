# 首都の一覧(Version 41)

各シナリオで、都市を持つ勢力の首都です。確かさは「確認」(史料で確かめられる)・「推定」(史料から推し量った・暫定)の2つで示します。
ゲーム中の遷都・建国でできた首都は、ゲームの中で「ゲーム中の遷都」「ゲーム中の建国」と記録します。表にない勢力(ゲーム中にできた国など)は、いちばん格の高い都市を「推定」の首都にします。
