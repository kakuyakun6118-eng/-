# 『五胡乱華』仮想シナリオ「炎漢再興 ― 天命を継ぐ者」の報告

LG gram・iPhone の実機での確認は、まだしていません(**未検証**)。結果は、すべてこの作業用の環境(ソフトウェアで描画するブラウザ)での確認です。

## 1. シナリオ

- ID は s304v。シナリオ選択画面に「仮想シナリオ」の区分を作り、史実のシナリオ(年の順)のあとに並べました。
- 開始は304年10月。もとは史実の304年の勢力図(シナリオ「五胡十六国の幕開け」)です。変えたのは、劉皓の楚の独立に伴う次の点だけです。
  - 領土:襄陽・江陵・宛・新野・武昌を楚のものにしました。
  - 人物:史実で荊州にいた劉弘は上庸へ、陶侃は長沙へ移しました。
  - 外交:楚は西晋と戦争、東海王 司馬越とは敵対、成とは友好です。
- 新野は、史実のシナリオの地図にない都市です。このシナリオだけに置く仕組みを作りました。ほかのシナリオの地図には出ません。
- 首都は襄陽です。金200,000・兵糧1,000,000・武将23人で始まります。
  - 金と兵糧は、シナリオで蓄えを決めた勢力に限り、蔵の上限と蓄えの目減りの基準をその量より下げません。そうしないと、兵糧が最初の月に2年分の上限まで切られるためです。
- 総兵力100,000は、専用の8軍団の合計です。都市の守備兵とは別に数え、二重には数えません。
  - 皇龍禁軍20,000・神武軍15,000・天策軍15,000・白龍騎10,000・羽林騎10,000・玄甲軍10,000・神弩軍10,000・荊州水軍10,000。

## 2. 人物(23人。すべて架空)

- 架空の人物は、史実の台帳とは別のファイル(persons.virtual.json)に入れました。IDは「vh_」で始め、史実の同名の人物と混ざらないようにしました。
- 劉氏三代は、祖父 劉雄 → 父 劉浩 → 劉皓 として家系図に登録しました。
  - 劉皓(280年生):120/115/118/115/120
  - 劉浩(249年生):94/72/115/118/105
  - 劉雄(218年生):108/103/108/110/110。高齢のため、没年は312年(ゲーム上の設定)としました。
- 家臣20人は、指示どおりの年齢と能力値です。全員に列伝・性格・得意兵科・特殊能力・初期の所在(楚の都市)を付けました。人物画面に、性格と特殊能力も出ます。

## 3. 能力値の上限120

- 上限120は、仮想シナリオだけです。史実の人物の能力値は変えていません(史実の人物の最高は97)。
- 100で切り捨てていた2か所(年少の成長の計算、後継者の教育)を、シナリオの上限に合わせて直しました。もとの値が上限より高くても切り捨てません。
- 確かめた場面:戦闘(統率120は100より強い。動かせる兵数は68,000と60,000)、成長の計算、1年の進行、セーブとロード、人物画面の表示(数字は120、棒は上限で端まで届き、100を超えた分は色が変わる)。
- 内政・登用・外交の計算は値に比例する式で、上限の切り捨てはありません(コードを確かめました)。
- 難易度を変えても、劉皓の能力値は下がりません(テストで確認)。

## 4. 固有能力と特殊能力(効果表 virtualTraits.json に32種)

テストで1つずつ確かめた結果です。

| 能力 | 効果 | テストの結果 |
|---|---|---|
| 天命覇王 | 軍団の強さ・士気×1.5 | 強さ×1.50、士気60→90(85→100で止まる) |
| 軍神降臨 | 指揮下の部隊の戦闘能力×1.3 | ×1.30。8つ全部で×1.95(重なりの上限×2の内側) |
| 炎漢正統 | 登用+40ポイント・治安の戻り3倍 | 登用19%→59%、治安の戻り1日0.1→0.3 |
| 神算鬼謀 | 調略が強く、敵の調略に強い | 調略×1.8(玄機妙算と合わせて)、受ける調略は3割、見込みは90%まで |
| 盛世創造 | 金・兵糧の収入50%増 | 金×1.46(太守の能力と合わせ都市ごとに2倍まで)、兵糧×1.50 |
| 英傑帰心 | 忠誠上昇・在野の人物が自ら仕える | 忠誠の目安70→85、在野の人物(張方)が楚に仕えた |
| 不敗の軍略 | 兵糧の消費半分・疲れ軽減 | 1日の兵糧の減り1.0→0.5、疲れ6→3 |
| 絶世の英姿 | 外交・人物交流・後宮の好感度 | 友好度の上がり方10→16.5(弁舌の士と合わせ)、後宮の好感×1.5 |

- 重なりで異常な値にならないよう、上限を付けました。会戦×2、収入×2、治安×3、登用95%、調略90%で、確率は0〜100%に収めます。
- 3Dの会戦では、与える損害を√倍、受ける損害を1/√倍にしました。合わせて自動の決着と同じ倍率になります。
- 家臣の特殊能力の例:烈火先鋒(攻め×1.15)、長江の水将(水軍×1.25)、富国の策(太守の都市の収入×1.15)、仁医(負傷の治り2倍)など。20人分すべて効果表にあります。
- 水軍(第1段階):荊州水軍は川の上で強さ×1.3、行軍×1.5です。

## 5. 専用の事件(9件)

- 決まった年月ではなく、条件がそろった月に起こります。条件は領土・威信・人物の生存・軍事力・外交です。
- そろわないあいだは「未発生」のまま待ち、事件の一覧で条件と、足りない理由を見られます。条件がそろえば一覧から選んで発動できます。
- 選択肢の種類の名前は「王道・堅実・大胆」です。
- 仮想シナリオの事件は、このシナリオだけに出ます。

| 事件 | 主な条件 |
|---|---|
| 劉氏三代の集結 | 三代が生きて劉皓の国にいる |
| 楚王の挙兵 | 三代の集結のあと、3軍団・5万人以上 |
| 天下英傑の集結 | 挙兵のあと、8都市以上、または名声90かつ威信50以上 |
| 二つの漢 | 劉淵の漢があり、都市が700km以内 |
| 洛陽奪還 | 実際に洛陽を得ている |
| 長安入城 | 実際に長安を得ている |
| 大漢皇帝即位 | 劉皓が君主で、洛陽と長安、15都市以上、威信55以上 |
| 天下統一 | 中国本土の都市の8割以上 |
| 万国来朝 | 統一のあと、戦争していない外国が3国以上 |

- 「楚王のまま」を選ぶと即位は見送られ、1年たって条件がそろえば、また選べます。
- 楚王の挙兵の北上は、軍団が歩いて向かいます(瞬間移動しません)。テストでは1日の移動は最大75kmでした。

## 6. 皇帝即位

- 同じ勢力のまま、国号を楚から漢へ改めます。旗の色は朱、位は皇帝、称号は大漢皇帝です。
- 官職(尚書令・大将軍・司徒)、皇室(父を太上皇、祖父を太皇)、外交(晋とは戦争、ほかの皇帝の国は認めない、同盟国・属国は祝う)も改めます。
- 人物・軍団・兵・領土・財政・家系は、そのまま残ります(テストで、前後の値が同じことを確認)。国号・旗・位はセーブに残ります。
- 劉皓の国は、即位するまでは皇帝生活に入れません。即位すると2Dの皇帝生活に入れ、政治の委任(戦略AIが方針を持って動き続ける)も使えます。
- 宮廷のAIが、楚を勝手に皇帝の位にしないようにしました。即位は事件だけで起こります。

## 7. AI

- 劉皓の国(AI):漢の二つの都(洛陽・長安)を重く見ます。その都を持つ国には宣戦し、属国なら併合します。二つの都を得たあとは、天下統一のため、隣の最も強い国に宣戦します。
- ほかの国(仮想シナリオだけ):全体の国力の35%以上を持つ覇者に対し、小国は降り(臣従)、ほかの国は対抗の同盟を結びます。漢の都を持つ国は降りません。
- 実例:成が漢に臣従、拓跋部が楚に臣従、涼州と東海王の対抗連合など。
