## 2. 宣帝の血統

- 劉雄・劉浩・劉皓とその子孫は「宣帝の血統」です。どの世代も上限は120です。
- 子の能力:父母の高いほうと平均から決め、ばらつきと「型」(万能・軍事・知略・政治)の補正を加えます。
  - 7%は「天賦の才」(劉皓並み)で、各能力が112以上になり、劉皓の固有能力を3つ受け継ぎます。
  - 400人分の試算(テスト46):能力はすべて40〜120、合計の平均は562、全員が500以上、天賦の才は9%、4つの型すべてが出ました。
- 特殊能力:
  - 型の能力を1つ持ちます。
  - 父母の能力は35%で受け継ぎます。ただし劉皓の8つの固有能力は15%です。
  - 劉皓の固有能力がまれに直接現れることがあります(5%)。
  - 1人4つまでです。
- 教育の速さは2倍です(実際の計算に入っています)。
- 長期:300年で血統の人物は414人生まれ、能力の上限120を超えた人は0人でした。
  - 300年後の生存者の合計の平均は481で、世代を重ねると平均に近づきます。

## 3. 皇位継承の修正

- 原因:劉皓には子がいませんでした。父の劉浩が後継者になったあと亡くなり、劉氏の皇族がいなくなったため、「有力な武将」の採点で家臣の趙凌雲が継いでいました。
- 直したこと:
  - 子(劉承・劉威)を開始時から置きました。
  - 血統の君主の後継を次の順にしました:指名された後継者 → 嫡長子 → ほかの実子 → 孫・曾孫 → 兄弟 → 甥 → 父・祖父 → 劉氏の一族。
  - 劉氏がいるあいだは、家臣は継ぎません。楚王の時代も皇帝の時代も同じ順です。
  - 幼い後継者もそのまま継ぎ、摂政(太后や劉浩など)が付きます。
  - 皇統継承の能力を持つ人が継ぐと、継承争いが起きません。
- テスト46:劉皓が即位の前に亡くなる場合も、即位のあとに亡くなる場合も、劉承(4〜5歳)が摂政つきで継ぎました。
- テスト47:300年のあいだ、皇族がいるのに家臣が君主になったことは0回でした。

## 4. 西晋の滅亡と漢皇帝の即位

- 開始:国は楚、君主は劉皓(楚王)、首都は襄陽です。
- 西晋がある間は、洛陽・長安を持っていても即位できません(テスト46・44)。
- 西晋の滅亡を、年を決めずに実際の状態で判定します。
  - 朝廷(勢力)が滅びた場合、または君主が司馬氏でなくなった場合(皇統の断絶・禅譲)です。
  - テストでは304年の滅亡と、司馬氏でない君主への交代で確かめました。
  - AIだけの進行では、312年に西晋の君主が周玘(司馬氏でない)になった月でした。
- 事件の流れ:
  1. **漢室再興の詔**(新しい事件):西晋の滅亡のあと、血統の君主が楚を治めていると起こります。
  2. **漢皇帝即位**(群臣の推戴):選択肢は「即位」と「延期」です。延期すると、1年後にまた選べます。
     - AIは国力(都市3以上・安定)を見て決め、ふつうは即位を選びます。
  - 洛陽と長安を持っている必要は、なくなりました。
- 即位で変わること:
  - 国号は楚→漢、旗は朱、位は皇帝、称号は「漢皇帝」、元号は「建武」です。
  - 皇太子は原則として劉承、皇后は謝蓉です。
  - 父を太上皇とし、官職(尚書令・大将軍・司徒)を任命します。
  - 皇帝生活の2Dモードが開きます。
  - 勢力のIDは同じなので、領土・軍・財政・官職・外交・家系図はそのままです。劉淵の漢(han_zhao)とは別の勢力です。
- 名前:在位中は「漢皇帝・劉皓」と表示します(宮廷の画面に元号の年も出ます)。
  - 崩御すると、廟号 太祖・諡号 宣武皇帝、称号「漢太祖宣武皇帝」になります。
  - 即位の前に亡くなった場合は、皇帝の記録を作りません(テスト46)。
  - 称号はセーブに残ります。
- 2代目からの廟号・諡号は、実際の治世(在位の長さ・領土の増減・戦績・皇室の安定・天下統一・崩御の年齢)で決めます。同じ王朝の中で重なりません。
