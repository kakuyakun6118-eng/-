# Version 67 の報告:漢王朝の滅亡原因の調査・歴代皇帝の固有特性・王朝発展AI

LG gram・iPhone の実機では、まだ確認していません(**未検証**)。結果はすべて、この作業用の環境(ソフトウェアで描画するブラウザ)での確認です。
変えたのは仮想シナリオ「炎漢再興」だけで、史実のシナリオには効きません(テスト13・46・48で確認)。

## 1. Version 64 で漢が滅んだ根本の原因

詳しくは docs/v67-collapse-investigation.md にあります。

- **完全な再現はできません**(確認された事実)。
  - ゲームは読み込みの直後に、実際の時間で少し進みます。そのため、同じプログラム・同じ手順でも結果が変わります。
  - Version 64 のテスト45をもう一度走らせると、404年は59都市でした(報告では8都市)。
  - 9回の再現のうち2回(h7・h8)が、報告と同じ道筋(324年28都市・354年30都市)をたどり、どちらも382年1月に滅びました。
- Version 64 の報告の「404年までに西晋に滅ぼされた」は**誤り**でした。その回の楚は、404年に8都市・君主は家臣の宋配で、滅びてはいません。
- **根本の原因**(皇位継承だけではありません):
  1. **AIの性格の計算**
     - 能力値から性格を決める式では、能力の高い君主ほど「外交型」になりました。
     - 劉皓と劉雅のもとで47年間、宣戦も軍備の増強もしませんでした(野戦軍は5万のまま)。
  2. **劉皓個人への依存**
     - 漢の専用AIは「君主が劉皓であること」が条件でした。
     - 8つの固有能力も劉皓本人にだけ付いていて、劉皓の死で一度に消えました。
  3. **人材の枯渇**:年齢の近い建国の家臣20人が、340〜359年にまとめて老衰で亡くなりました。武将は51人から7人に減りました。
  4. **後継**:劉皓の子がいませんでした。架空の劉雅が継ぎ、その次は家臣の李離が継ぎました。
  5. **滅亡**:軍備を増やした東海王 司馬越が372年に攻め込みました。377年に首都の襄陽を西晋に奪われ、382年に滅びました。
  6. **テストの作りの問題**
     - プレイヤーの国(新羅)が滅ぶと、テストは楚をプレイヤーの国にしていました。そのため楚のAIが止まりました(6/9回)。
     - また、海の向こうの1都市の国との「届かない戦争」で、80年止まった回もありました。

## 4. 追加した固有特性と効果

### 漢の正統(皇帝の地位に伴う、国に1つだけの特性)

- 効果:
  - 全軍の戦闘力 +30%
  - 登用 +25ポイント
  - 忠誠・治安が毎月 +2
  - 金・兵糧の収入 +30%
  - 徴兵の効率 +25%(同じ金で集まる兵が多い)
  - 兵糧の消費 −25%
  - 外交 +30%
  - 皇族の伸び +50%
  - 反乱 −50%(継承争いにも効く)
- 値は virtualTraits.json で変えられます。
- 付く条件:
  - 劉皓本人か、父をたどって劉皓に着く直系の子孫で、漢の皇帝の位と記録があること。
  - 即位で付き、次の皇帝へ移ります。幼帝や摂政のときも続きます。
  - 家臣など血統でない者が君主になると止まります。
  - 劉淵の漢には付きません(テスト48)。
- 「宣帝の血統」(皇族の血統)とは別のものです。人物ではなく国に1つだけ付くので、皇族の人数で重なりません。
- 既存の「炎漢正統」は残しました。重なっても、会戦×2・収入×2・登用95%などの上限を超えません。
- 実際の計算で確かめたこと(テスト48):
  - 漢の軍団は、指揮官の能力がなくても会戦×1.3になる。
  - 1,000人の徴兵の金が166から133になる。
  - 補給の届かない所の兵糧の消費が1.421から1.066になる(0.75倍)。

### 皇帝個人の特性

- 劉皓:既存の8つの能力を保ち、型は覇王型です。
- 劉承(守成型・万能型の守成の名君):帝王之器・文武隆盛・万民帰心に、既存の仁政・皇統継承を加えた5つ。
- 劉威(覇王型):武神・破軍・遠征無双
- 劉睿(智帝型):神算鬼謀・王佐之才・富国強兵
- 劉弘(明君型):中興之主・文武双全・盛世創造
- 既存の能力も、指示の説明に合うよう強めました。
  - 帝王之器:収入・外交・全軍の強さ
  - 破軍:攻城
  - 中興之主・盛世創造:人口の増え方
  - 文武双全:君主のときに全軍の強さと収入
  - 富国強兵:徴兵
  - 王佐之才:登用

### 第4世代からの自動の特性

- 9つの型があります:覇王・武帝・仁君・明君・賢帝・智帝・富国・中興・守成。
- 型は即位のときに、能力・すでに持つ特性・教育の方針・経歴(失った都市・国の大きさ・安定)から選びます。
- 特性は3〜5つです。型の特性を必ず1つ持ちます。
- 新しい特性15種:覇王の威・天下布武・武帝の軍制・精兵養成・慈愛の治・求賢令・太学振興・合従連衡・通商振興・屯田の制・失地回復・守成の徳・辺境鎮撫・文武隆盛・万民帰心。
  - それぞれ会戦・徴兵・兵糧・収入・忠誠・治安・反乱・人口・皇族の伸び・外交・AIの性格のどれかに効きます。
- 決めた型と特性はセーブに残り、ロードで変わりません(テスト48)。

## 5. 歴代皇帝のAIの変化

- **なぜ戦争をしなくなったか**(Version 65):
  - 統一のあと、残りはみな属国(西域は自治のため併合しない)と、動かない諸部族だけで、相手がいませんでした。
  - 能力の高い皇帝は「外交型」の性格になっていました。
- **直したこと**:
  - 性格:皇帝になってからは、型と能力値を半分ずつ合わせ、特性の傾きを足します。即位の前は、これまでどおりです。型の性格を建国期から使うと、無謀な多方面の戦争で305年ごろに滅ぶ回があったためです。
  - 国家目標:皇帝ごとに3〜4つです(中国統一・失地回復・国境防衛・西域遠征・シルクロードの支配・周辺勢力の属国化・経済と人口・軍事力・人材・首都の発展)。
    - 統一すれば西域・シルクロード・属国化へ、都市を大きく失えば失地回復へ、毎月見直します。
  - 拡大の目標があれば、戦争がなくても方針「外交」で止まらず、外へ出ます。
  - 目標ごとの行動:
    - 失地回復:失った都市を狙う
    - 西域遠征・シルクロード:中国本土の6割を持ったあとだけ、西域を狙う
    - 属国化:弱い隣国に従属を求める
    - 西域遠征・シルクロード:10年以上従えた西域の属国を直轄の地にする
    - 軍事力の強化:軍備を増やす
    - 発展:首都を先に開発する
  - 届かない戦争:方針と宣戦の枠に数えず、2年続けば和平を申し入れます。
  - 無謀な遠征の歯止め:漢の西域遠征は、失敗が勝ちより3回多くなると10年控えます(s8:40回の失敗 → 3回)。
  - 劉皓だけだった漢の専用AIを、血統の君主すべてに広げました。

## 10. まだ作っていないこと・未検証・分かっている問題

- **地図の広さの限界**
  - 統一すると、2代目からは地図にほぼ相手がいません。人口・金も上限に達し、領土が「90→90」の皇帝が続きます。評価はほとんど「守成の君」です。
  - 新しい地図や国の追加は、今回の対象外です。皇帝ごとの違いは、内政・外交・人材(特性の効果)には出ますが、領土には出にくいままです。
- **建国期の滅亡**:劉皓が楚王の時代の滅亡は、Version 64・65 と同じく、20回のうち3回ありました。建国期のAIは変えていません。
- **大きくなれない回**:M3 は300年続きましたが、334年から11都市のまま広がりませんでした。原因はまだ調べていません。
- 「人材の育成」の目標は、特性(皇族の伸び・登用)の効果だけで、AIの専用の行動はありません。
- 「破軍」の「敵の士気を下げる」は作っていません(攻めと攻城の強さだけ)。
- 西域遠征を控える期限は、セーブに残りません(ロードすると歯止めが外れる)。
- 長期試験は「楚以外をプレイヤーの国にする」作りです。乱数の種が同じでも、読み込み直後の進み方で、少しずつ結果が変わります。
- LG gram・iPhone の実機での確認は**未検証**です。
