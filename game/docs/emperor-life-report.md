# 皇帝生活モード(3Dの後宮)の報告 — Version 41 仕様変更指示

この文書の「確かめた」は、すべて**開発環境の自動テスト**(Playwright・ソフトウェア描画の Chromium。iPhone は画面の大きさとタッチの模擬)の結果です。**実機(LG gram・iPhone)では確かめていません。**

## 1. 入り方と全体の流れ

- **入り方**:「メニュー」の「皇帝生活(後宮へ)」、または「皇室」の画面の「皇帝生活(後宮へ)」。
- **政治の委任**:宮殿に入ると、政治・軍事・外交・財政を重臣(AI)に任せます。
  - 自国も、ほかの国と同じ戦略AIが動かします(出兵・防衛・外交・内政・人事・後継者・子女の教育)。
  - 会戦・歴史の事件・外交の申し入れも、AIが決めます。宮殿にいるあいだ、会戦の準備画面は開きません。
  - ただし、**皇帝の婚姻だけは、AIに決めさせません**(後宮で本人どうしが決める)。
- **時間**:宮殿の1日(朝・昼・夕・夜)は、戦略マップの1日です(1刻 = 4分の1日)。
  - 「時を進める」「一日を終える」「十日を過ごす」「一月を過ごす」と、「時の流れ」(既定で120秒ごとに次の刻)で進みます。
  - 進めているあいだも、他国と歴史の事件が進みます。毎日の行動は義務ではなく、歩き回るだけでもかまいません。
- **介入**:「政務に戻る」で、委任をやめて戦略マップの操作に戻ります。「上奏」の画面からも戻れます。
- **セーブ・ロード**:宮殿の「メニュー」から、いつでもできます。宮殿で保存したデータを読み込むと、宮殿に戻ります。

## 3. 人物(NPC)

- **人数**:317年の東晋で14人(テストの値)。
  - 史実の女性3人:鄭阿春(晋王の夫人)・庾文君(世子の妃)・衛鑠。
  - 架空の女官11人。女官の人数は、国の都市の数で8〜14人です。
- **後宮に出す人**:
  - 皇帝の妃。
  - 都にいる成人(18歳以上)の女性(史実の人物)。
  - 架空の女官(名前・出身・役職は、国ごとに決まった値で作ります)。
  - 架空の女官は、妃に迎えるまで人物の台帳に入れません。俸禄や忠誠の計算を変えないためです。
- **一人ずつの情報**:人物ID・氏名・年齢・出身・身分と役職・3Dの姿(衣の色・縁取りの色・髪の形・背の高さ)・肖像・性格・好み・親密度・信頼・恋愛感情・皇帝への評価・嫉妬・ほかの人への気持ち・将来の希望。
  - **肖像**:史実の人物は、これまでの肖像の絵を使います。絵の無い人と架空の女官は、衣の色と髪の形から作った似顔です(写実ではありません)。
- **性格6種**:温和・快活・内気・聡明・気位が高い・情が深い。
- **好きなこと7種**:詩歌・琴と笛・書画・舞・刺繍・薬草と花・囲碁。
- **将来の希望7種**:家族を助けたい・学問・穏やかな暮らし・女官の長・宮を出たい・役に立ちたい・妃になりたい。
- **会話**:あいさつ・好きなことの話・希望の打ち明け・仲のよい人や合わない人の話・皇帝への気持ちが、性格・時刻・信頼・恋愛感情・評価で変わります。
  - テストでは、6人に話しかけて6通りの会話になりました。
  - 会話はゲームのための創作で、史料の言葉ではありません。
- **日常の行動**:朝・昼・夕・夜で居場所としていることが変わります(例:朝は詰所、昼は庭園、夕は宴会場で琴を弾く、夜は居所)。時刻が変わると、区画の入口を通って歩いて移ります。

## 4. 交流と恋愛

| 交流 | 内容 |
|---|---|
| 話す | 親密度が上がる。同じ日の繰り返しは効き目が小さい |
| 贈り物 | 8種(絹・玉の簪・香・書物・琴の譜・花・菓子・筆と硯)。国庫の金を使う。好みの品は喜び、苦手な品は喜ばない |
| 庭園・食事に誘う | 信頼・親密度・機嫌・性格で、応じるか断るかが決まる。断られたら、そのまま受け止める |
| 詩歌・音楽を楽しむ | 得意な芸なら、評価と親密度が大きく上がる |
| 相談を聞く | 将来の希望や人間関係から相談が生まれる(家族の病・学問・女官の長・宮を出たい・口論・後継)。答え方で信頼が変わる。「宮を出たい」は、許せば本人の望みどおり宮を出る |
| 宴 | 宴会場で、招く人を選ぶ(金200・夕か夜)。節句(元会・上巳の曲水の宴・七夕・重陽)なら喜びが大きい |
| 想いを伝える | 恋人の間柄に |
| 妃に迎えたいと伝える | 妃に。女官なら人物の台帳と婚姻に加わる |
| 皇后に立てたいと伝える | 皇后がいないときだけ。皇室の正室の冊立 |

**本人の意思について**(指示書の第5章):

- 告白・妃・皇后は、**相手が決めます**。決まり方は、恋愛感情・信頼・皇帝への評価・性格・将来の希望・嫉妬です。くじ引きではないので、繰り返して「はい」を引き出すことはできません。
- 断られたら、**30日は同じ申し出をしません**(選べない理由として「気持ちを尊重し、時を置きます」と示します)。地位を使って強制したり、断りを無視して進めたりする選択肢はありません。
- 「宮を出たい」「学問を続けたい」という希望の人は、妃になることを断ります。気持ちが離れれば、恋人の間柄は終わります(本人の意思)。
- 恋愛の選択肢を出さない相手:未成年・皇帝の近親・皇族の女性・皇太后・ほかの人の妻。女性の君主の場合も、いまは恋愛を用意していません。

## 5. 後宮の人間関係

| 要素 | 内容 |
|---|---|
| 友情・対立 | 一人ずつ、ほかの人への気持ち(-100〜100)を持つ。同郷・性格の相性・妃どうしの張り合いで、はじめの値が決まる |
| 嫉妬 | ほかの人に寵愛を示すと、皇帝に想いを寄せる人の嫉妬が増える(気位が高い人ほど)。嫉妬が強いと口論が起き、相談が生まれる |
| 寵愛の競争 | 宴に招かれなかった妃は寂しく思う。会えない日が続く妃は、評価が少しずつ下がる |
| 派閥 | 皇后・妃を頭に、気持ちの近い人が集まる(子がいれば強い) |
| 後継争い | 子のいる妃が2人以上いると、子を後継にと相談する。指名すると、皇室の後継者の指名(既存の仕組み)を使い、ほかの妃の嫉妬が増える |
| 外戚 | 寵愛を受ける妃・新しい妃の一族(同じ姓・同じ民族の臣下)の忠誠が上がる(既存の忠誠の仕組み) |

## 6. 皇室・子女

- 妃・皇后は、既存の皇室の婚姻(正室・側室)として記録します。家系図・子女の誕生・皇位継承は、既存の仕組みのままです。
- 「子女」の画面で、皇帝の子女(年齢・母・後継者かどうか)を示します。未成年(6歳以上)は、教育の方針を選べます(既存の教育の仕組み)。
- **未成年は、後宮の交流の相手に入れません**。成人の恋愛と、未成年の養育は、別の画面に分けています。

## 7. 政治のAI(重臣)

- 宰相・将軍・外交官・財政担当を、その国の臣下で能力のいちばん合う人に充て、いまの様子(国の安定と方針・軍団と戦争の相手・同盟・国庫)を示します。
- 実際の判断は、ほかの国と同じ戦略AI・外交AI・財政・皇室のAIが行います。
- **上奏**:宮殿にいるあいだの知らせのうち、自国に関わる重要なこと(戦争・都市・宮廷・外交)と、後宮のこと(病・口論・節句)だけを示します。
- テスト(317年・東晋・半年):宮殿で過ごすあいだに、次のことが起きました。
  - 自国のAIの判断の記録 18件、知らせ 38件、上奏 21件。
  - 重臣は 宰相:王導・将軍:祖逖・外交官:温嶠・財政担当:陶侃。
  - 会戦の準備画面は一度も開きませんでした。

## 9. まだのこと・確かめていないこと

- **実機(LG gram・iPhone)での確認**:していません。とくに、iPhone での描画の速さ、指の操作のしやすさ。
- **3Dの細部**:建物の中の調度は少なく、人物の顔の表情・歩き方の動きは簡単なものです。浴殿は建物と湯船だけです(湯浴みの場面はありません)。
- **会話**:決まった文の組み合わせです。人物ごとの長い物語や、選択肢の多い会話の分かれ道は、まだありません。
- **宮廷事件**:病・口論・節句・後継の相談だけです。陰謀・毒殺・廃后などの大きな事件は、まだありません。
- **皇后がいるとき**:新しい皇后は立てられません(廃后の仕組みはありません)。
- **女性の君主**:後宮の恋愛はありません(宮殿を歩き、交流することはできます)。
- **重臣への個別の指示**:できません。重臣はAIとして自分で決めます。介入は、戦略マップに戻って行います。
