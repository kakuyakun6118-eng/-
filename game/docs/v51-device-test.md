# 『五胡乱華』実機テスト手順書(Version 51:帰城・軍団結合)

対象:**LG gram 2in1 14T90S-MA55J**(マウス・タッチパッド・タッチ)と、**iPhone**(縦向き・横向き)。

この手順書の項目は、**あなたが実機で確かめるまで、すべて「未検証」**です。
開発環境の自動テスト(ソフトウェア描画の Chromium。iPhone は「iPhone 13」の画面の大きさとタッチの模擬)で確かめたことは、いちばん下の欄に分けて書きました。自動テストで通っても、実機での確認の代わりにはなりません。
結果の欄に ○・×・気づいたことを書いてください。Version 42 の手順書(docs/v42-device-test.md)の項目も、あわせて確かめてください。

公開ページ:https://claude.ai/artifact/TQjDQDtrwsxCQDT5eVqhiM

## 1. 帰城

準備:東晋(317年)を選び、建康のそばの軍団をタップ(クリック)する。

| 番号 | 手順 | 期待する結果 | LG gram | iPhone |
|---|---|---|---|---|
| 1-1 | 軍団の欄の「帰城」を押す | 帰城先の一覧が出る。「出発元」「最寄り」「首都」の印、距離・日数・道中の兵糧の消費・着いたときの残りが読める | | |
| 1-2 | 一覧を指(ホイール)で上下に動かす | 一覧だけが動き、地図や画面全体は動かない | | |
| 1-3 | 遠い都市(100km以上)を選ぶ | 地図に道のりが出て、「確定」「キャンセル」が出る | | |
| 1-4 | 「確定」を押し、時間を進める | 軍団が道に沿って少しずつ進む(一瞬で着かない)。軍団の欄に「〇〇へ帰城中」 | | |
| 1-5 | 着いたら、その都市をタップする | 守備兵が軍団の兵の数だけ増え、軍団は地図から消える。人物の画面で、指揮官がその都市にいる | | |
| 1-6 | すぐそばの都市(「すぐそば・その場で入城」)を選ぶ | その場で入城し、知らせが出る | | |
| 1-7 | 帰城の途中で、帰城先が敵に落とされる(または、落とされそうな都市を選んで待つ) | 帰城が取り消され、軍団の欄に「奪われたため、帰城を取り消しました。別の帰城先を選んでください」。もう一度「帰城」で別の都市を選べる | | |

## 2. 軍団結合

準備:同じ国の軍団を2つ以上用意する(都市で出陣する)。

| 番号 | 手順 | 期待する結果 | LG gram | iPhone |
|---|---|---|---|---|
| 2-1 | 軍団をタップし、「軍団結合」を押す | 同じ国の軍団の一覧(兵の数・指揮官・距離)と、チェックの枠が出る | | |
| 2-2 | 近くの軍団にチェックを入れる | 「結合後:〇〇人(歩・騎・弓)・兵糧・士気・疲労・行軍の速さ・総指揮官・副将・配下」の見込みが出る | | |
| 2-3 | 「結合後の総指揮官」の選択で、別の武将を選ぶ | 見込みの総指揮官が変わる | | |
| 2-4 | 「結合する」を押す | 2つの軍団が1つになり、兵の数が見込みどおり。軍団の欄に「副将」「配下」が出る | | |
| 2-5 | 遠く(40km以上)の軍団を選んで結合する | 遠い軍団が、結合先のそばまで進んでから1つになる(一瞬では結合しない) | | |
| 2-6 | 3つ以上の軍団にチェックを入れて結合する | すべてが1つになる | | |
| 2-7 | チェックの枠・選択・釦を指で押す(iPhone) | 押し間違えずに操作できる(押せる大きさか) | — | |

## 3. 大軍の駐屯と兵站

| 番号 | 手順 | 期待する結果 | LG gram | iPhone |
|---|---|---|---|---|
| 3-1 | 守備兵の多い都市に、大きな軍団を帰城させる | 従来の上限(例:建康の規模で2万人)を超えても、兵は消えずに残る | | |
| 3-2 | 財政の画面を開く | 守備兵の維持費と兵糧の支出が増えている | | |
| 3-3 | 数か月進める | 人口に見合わない大軍のいる都市では、治安が少しずつ下がる(急には下がらない) | | |
| 3-4 | 大軍団(5万人ほど)の行軍の速さを見る | ふつうの軍団より遅い(軍団の欄の「行軍速度」) | | |
