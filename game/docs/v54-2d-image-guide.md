# ChatGPT で作る絵の指示書(皇帝生活モード・2D版)

この指示書で、ChatGPT に後宮の絵を作ってもらいます。できた絵は、このチャットに貼ってください。こちらで小さく圧縮して、ゲームに登録します。

**ファイル名は付けなくて大丈夫です。** 貼るときに「A1 の通常」「庭園の昼」のように一言添えてください。

---

## 1. 作る絵の一覧と、優先する順

| 順 | 絵 | 枚数 | 必ず要るもの |
|---|---|---|---|
| ① | 物語の主要6人(A1〜A6)の肖像 | 6人 × 8表情 = 48枚 | まずは「通常」と「微笑み」だけでも可 |
| ② | 一般の人物(N01〜D01、16人)の肖像 | 16人 × 1〜8表情 | 「通常」は必ず。ほかの表情は、あればなお良い |
| ③ | 8区画の背景(昼・夜) | 16枚 | 昼と夜 |
| ④ | 8区画の背景(朝・夕) | 16枚 | 無くてもよい(昼の絵の色を変えて代わりにする) |
| ⑤ | 特別な場面の一枚絵 | 7枚 | 無くてもよい |

足りない表情は、近い表情で代わりにします。
- 喜び → 微笑み
- 照れ → 微笑み
- 驚き → 通常
- そのほか → 通常

## 2. 肖像画の決まり(全員に共通)

ChatGPT には、最初に次の文を送ってください。

```
これから、中国・魏晋の時代(4世紀、東晋のころ)の後宮の女性の肖像画を、何人分も作ってもらいます。全員に共通の決まりです。
・写実的なデジタルペインティング。写真のように自然な肌・目・鼻・唇。アニメ調・漫画調にしない
・腰から上の半身像。体はやや斜め、顔はこちらを向く。視線はこちらか、少し外す
・縦長(1024×1536)。背景は透明
・柔らかい自然な光。高解像度。髪の毛の流れ・髪飾り・衣の刺繍まで精巧に
・衣装は魏晋の宮廷の服(交領の上襦・長い裙・広い袖・披帛)。唐や清の服にしない
・すべて成人の女性(年齢は指定どおり)。品のある姿で、肌の露出は控えめに
・文字・サイン・枠を入れない
```

人物ごとに、次の形で頼んでください。

```
人物 A1、20歳。詩歌を愛する女官。知的で穏やか。切れ長の目、細い柳眉、薄化粧。淡い青緑の上襦に白い長裙。簡素な一つまげ(単髻)に銀の簪一本。表情は「通常(穏やかな無表情)」。
```

### 表情の差分(同じ人物のまま、表情だけを変える)

1枚目(通常)ができたら、その絵を ChatGPT に渡したまま、次のように頼んでください。

```
この画像と同じ人物・同じ顔立ち・同じ髪型と髪飾り・同じ衣装・同じ構図と光のまま、表情だけを「微笑み」にしてください。背景は透明のまま。
```

「微笑み」のところを、次の8つに替えて頼みます。
- 通常(穏やかな無表情)
- 微笑み(口元がやさしくほころぶ)
- 喜び(歯が少し見える明るい笑顔)
- 悲しみ(眉が下がり、目が潤む)
- 怒り(眉を寄せ、口を結ぶ。上品に)
- 困惑(眉をひそめ、首を少しかしげる)
- 驚き(目を見開き、口が少し開く)
- 照れ(頬を赤らめ、目をそらしてはにかむ)

**大事なこと:** 顔立ちが変わってしまったら、作り直してもらってください。表情ごとに顔が違って見えないことが、いちばん大切です。

### 誰がどの絵になるか(ゲームの側で自動で決めます)

- 物語の役を持つ人物には、その役の絵(A1〜A6)を使います。
- ほかの人物には、年齢と身分の近い絵(N・L・S・D)を割り当てます。
- 割り当ては人物ごとにセーブに残るので、途中で顔が変わることはありません。

## 4. 背景画(8区画)

最初に、次の文を送ってください。

```
これから、中国・魏晋の時代(4世紀)の宮殿の後宮の背景画を作ってもらいます。共通の決まりです。
・写実的なデジタルペインティング。横長(1536×1024)
・人物は描かない(あとで人物を重ねるため)。画面の下の3分の1は、人物が立てる床や地面にする
・建物は魏晋の様式(朱の柱、灰色の瓦、反りのある屋根、木の格子、几帳・屏風・敷物。椅子は使わず床に座る文化)
・文字・サイン・枠を入れない
```

場所ごとに、「(場所)の(時刻)」として頼んでください。例:「後宮の庭園の昼」。

| ID | 場所 | 説明 |
|---|---|---|
| emperorHall | 皇帝の寝殿 | 広く格式のある殿舎の中。奥に御座と屏風、几、香炉、帳 |
| empressPalace | 皇后の宮殿 | 華やかで落ち着いた殿舎の中。牡丹の屏風、鏡台、刺繍の几帳 |
| consortQuarters | 妃たちの居所 | 小ぶりで優雅な部屋。帳のある寝台、琴、花を生けた器 |
| ladiesStation | 女官の詰所 | 実用的な部屋。棚、機(はた)、文机、巻物、衣を畳む台 |
| garden | 後宮の庭園 | 池と太鼓橋、亭(あずまや)、岩、柳と梅、遠くに殿舎の屋根 |
| bath | 浴殿 | 石造りの湯殿。湯気、木の桶、薄絹の帳(人物は描かない) |
| banquet | 宴会場 | 広間に低い膳が並び、楽人の台、灯籠、華やかな敷物 |
| corridor | 回廊 | 朱の柱が続く屋根つきの回廊。欄干の向こうに中庭 |

時刻の言い方:
- 朝:朝もや、淡い光
- 昼:明るい日差し
- 夕:夕焼けの金色の光
- 夜:灯籠と燭台のあたたかい灯、月明かり

**昼と夜の16枚が、まず要ります。** 朝と夕は無くてもかまいません(昼の絵の色を変えて代わりにします)。

## 5. 特別な場面の一枚絵(無くてもよい)

| ID | 場面 |
|---|---|
| ev_scholar | A1 が月の下の回廊で、皇帝に自作の詩を詠み聞かせる |
| ev_ambitious | A2 が女官を束ねる尚宮として、殿舎で居並ぶ女官に指示を出す |
| ev_provincial | A3 が故郷からの便りを胸に抱き、庭園の池のほとりで涙ぐむ |
| ev_attendant | A4 が主の皇后の後ろに控え、深く拝礼する |
| ev_consort | A5 が宴の灯の中、皇帝の隣で琴を奏でる |

## 6. 注意

- 他の人の作品(ネットで見つけた絵など)を、そのまま貼らないでください。ゲームに使える絵は、自分で ChatGPT に作らせたものだけです。
- ChatGPT で作った絵の利用条件は、OpenAI の利用規約に従います。
- 全員を成人として描いてください(年齢は一覧のとおり)。
