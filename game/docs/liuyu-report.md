## 5. 会戦

- **却月陣**(新しい陣形):河を背に戦車を三日月に並べる。騎兵の突撃に強く(敵の騎兵は平地の突撃の利を失う)、大弩が騎兵によく当たる。動けず、崩れると河に追い落とされて損害が大きい。3Dの会戦では、事件で指定された側の歩兵・弓兵がはじめから陣を組み、陣形の切り替えにも出ます。
  - テストの結果(自動の決着の見積もり):晋7,000(弓兵3,000)対 北魏の騎兵中心21,000 → 晋の勝率 **陣なし2% → 却月陣46%**。歩兵中心の敵には 2% → 4%(ほとんど効かない)。騎兵66,000には陣があっても3%(負ける条件)。敗れたときの損害は陣で59%、陣なしの接戦の敗北で22%。
- **特殊会戦**(6つ):臨朐(平地の決戦)、広固攻城戦(城内の飢えで士気-10)、洛陽攻略(援軍なしで士気-15)、却月陣、長安攻略(渭水からの奇襲で攻め手の士気+5・×1.06)、関中防衛(諸将の不和で守り手の士気-8)。勝敗は決めていません。
- **劉裕の特性**:北府軍(歩兵の割合に応じ最大+8%、3Dでは歩兵の士気+6)、北伐の雄(攻める側+8%、城攻め+12%)、水陸並進(行軍+12%・補給の届く範囲2倍)、開国の英傑(捕らえた国に仕えにくい)、百戦錬磨(+4%、負けても捕らわれ・討たれる見込みが4割)。
  - テスト:同じ能力で特性なしと比べ、勝率71%→81%。400回の負け戦で、捕らわれ・討たれた回数は特性なし49回・劉裕17回(0回ではない=不敗ではない)。
- 戦場の実地形(標高・土地被覆)の高解像度データは、これらの戦場では未収録です(戦略マップの標高で代用。これまでと同じ表示)。

## 6. 戦略AIの成功・失敗の例

- 北伐の好機:北伐の雄のいる国は、君主の死・安定の低下・幼い君主・後秦の後継争いがある国の都市を重んじ、宣戦の相手にも選びやすくしました。
- 夏の赫連勃勃:関中の都市の持ち主が遠い国(都から700km超)か守りが手薄(6,000未満)で、劉裕が近くにいなければ狙います。
- 遠い城を落とした北伐の雄の軍は、兵の15%(最大4,000)を守備兵として残します。
- 直した不具合:史実の会戦の前の集結が、すでに前線にいる軍団を後ろの都市へ呼び戻していました(劉裕の軍が臨朐から下邳へ戻されていた)。
- 歴史の事件の攻城に失敗しても、兵と兵糧が十分なら包囲(兵糧攻め)に移ります。
- 例(409年開始・AIのみ):臨朐で晋が勝利 → 広固の力攻めは失敗 → 包囲 → 盧循の反乱で劉裕が建康へ帰り、南燕は生き残った(「南燕の存続」の道)。
- 例(416年開始・通常モード):洛陽の救援に後秦の軍が向かい、洛陽は落ちず。長安でも後秦が勝つ。劉裕は関中に留まり、422年の劉裕の死のあと宋は分裂した(「後秦の再建」「北魏が北伐を止める」に近い道)。
- 例(416年開始・史実重視):洛陽奪還 → 劉裕は建康へ帰る → 420年に宋の建国。
