# Version 53 実機での確かめ方(LG gram・iPhone)

この手順は、まだ実機で行っていません。開発の環境では、ソフトウェア描画(SwiftShader。GPUを使わない描画)だけで確かめています。
数字(FPS など)は、実機ではかなり違うはずです。実機で確かめたら、結果を下の表に書いてください。

公開版:https://claude.ai/artifact/TQjDQDtrwsxCQDT5eVqhiM

## 1. LG gram(Windows・Chrome または Edge)

### 準備
1. Chrome(または Edge)で公開版を開く。電源は「AC につなぐ」「最高のパフォーマンス」にする(電池だけだと遅くなります)。
2. 開始の画面で「317年」を選び、晋(東晋)で始める。
3. 宮廷の画面から「後宮へ(皇帝生活)」を押す。

### 画質と速さ
1. 右の「画質」ボタンで、低→中→高 と切り替える。
2. それぞれ 30 秒ほど、庭園(池のまわり)と回廊を歩く(WASD・矢印)。
3. F12 → 「パフォーマンス」タブ、または「レンダリング → FPS メーター」で FPS を見る。
4. カクつく(30 FPS 未満が続く)なら、画質を一つ下げる。

### 操作
| 確かめること | 操作 | よい結果 |
|---|---|---|
| 歩く | WASD・矢印 | 壁・柱をすり抜けない |
| 話しかける | 人物に近づいて F(または Enter)、またはクリック | 交流の欄が開く |
| 視点 | ドラッグで回す・ホイールで拡大 | 回廊の中でも、カメラが屋根や壁にめりこまない |
| 時を進める | 「時を進める」「一日を終える」 | 人物が歩いて次の居場所へ移る(目の前で消えたり現れたりしない) |
| 物語 | 主要な6人に話しかけ、「第n段階へ進む」 | 場面と選択肢が出る |
| 事件 | 右の「宮廷の事件」 | 起きたわけ・選択肢が出て、押すと結果が出る |
| 環境音 | 音楽の音量を上げ、庭園の池 → 皇帝の殿 と歩く | 池の近くで水の音が強く、室内で弱まる(録音ではなく合成音) |

### 往復(資源の漏れ)
1. 「政務に戻る」→ 宮廷の画面 → 「後宮へ」を 10 回くり返す。
2. タスクマネージャー(Shift+Esc)で、タブのメモリが増え続けないかを見る。

## 2. iPhone(Safari)

### 準備
1. Safari で公開版を開く。横向きにする。低電力モードは切る。
2. 317年・晋で始め、「後宮へ」を押す。画質は、はじめから「低」になります。

### 操作
| 確かめること | 操作 | よい結果 |
|---|---|---|
| 歩く | 画面の左下を指でなぞる(仮想スティック) | なぞった向きに歩く |
| 移動 | 床をタップ | その場所まで歩く |
| 視点 | 右側をスワイプ・2本指で拡大 | 視点が回る・寄る |
| 話しかける | 人物をタップ | 交流の欄が開く。ボタンが指で押せる大きさ |
| 物語・事件 | 「第n段階へ進む」「宮廷の事件」 | 欄が画面からはみ出さない |
| 画質 | 「画質」で 低→中 | 中でカクつくなら、低に戻す |

### 長く遊ぶ
1. 「一月を過ごす」を 12 回押して、1年進める。
2. 熱くなりすぎないか、落ちないかを見る。
3. メニューからセーブ → 再読み込み → ロードして、後宮の人物・物語・事件が同じかを見る。
