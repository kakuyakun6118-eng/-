# 写真の差し替え方

このフォルダに以下のファイル名でJPEG画像を置くと、アプリのイラストの代わりに
その写真が使われます。置かなければ内蔵イラストがそのまま表示されます。

| ファイル名 | 対応する行き先 | 状態 |
| --- | --- | --- |
| `skyline.jpg` | 展望台(エンパイア、トップ・オブ・ザ・ロック、サミット)、夜景 | ✅ 配置済み |
| `bridge.jpg` | ブルックリン・ブリッジ、マンハッタン・ブリッジ、ダンボ | ✅ 配置済み |
| `times-square.jpg` | タイムズスクエア、ブロードウェイ、劇場 | ✅ 配置済み |
| `liberty.jpg` | 自由の女神、エリス島 | ✅ 配置済み |
| `downtown.jpg` | ワンワールド、9/11メモリアル、ウォール街、バッテリーパーク | ✅ 配置済み |
| `stadium.jpg` | ヤンキースタジアム、シティ・フィールド、野球観戦 | ✅ 配置済み |
| `park.jpg` | セントラルパーク、ハイライン、ブライアントパーク | ✅ 配置済み |
| `brownstone.jpg` | ハーレム、ウィリアムズバーグ、ソーホー、街歩き | イラスト表示中 |

## バナーの選ばれ方

しおりの日別バナーは、**その日の予定に入っている行き先に合わせて自動で選ばれます。**
たとえば自由の女神を回る日は自由の女神の写真、セントラルパークの日は公園の写真になります。

- 同じ写真が複数の日で重複しないよう、1日1枚ずつ割り当てます
- 行き先が上の表に当てはまらない日は、まだ使っていない写真が順に使われます
- 予定を組み替えると、バナーも自動的に追従します

`skyline.jpg` はアプリ上部のヘッダーとAI提案タブでも使われます。

## 新しい写真を追加したら

`src/components/Scene.tsx` の `PHOTO_SCENES` にそのシーン名を追加してください。
写真のあるシーンが優先的に選ばれるようになります。

## おすすめのサイズ

横1200px前後、縦横比はおおよそ 5:2(横長)。1枚300KB以下にしておくと
iPhoneでの表示が軽くなります。

## 無料で使える写真の入手先

商用・私的利用ともに無料で、クレジット表記も不要な素材サイトです。
「New York」「Brooklyn Bridge」などで検索してダウンロードしてください。

- Unsplash: https://unsplash.com/s/photos/new-york
- Pexels: https://www.pexels.com/search/new%20york/
- Wikimedia Commons(パブリックドメイン): https://commons.wikimedia.org/

旅行から帰ったあとに、ご自身で撮った写真に差し替えると
そのまま思い出のアルバムとしても使えます。

## 置いたあとの反映

ローカルで確認する場合は `npm run dev` を再起動してください。
公開版に反映する場合は、ファイルを追加して `main` ブランチにpushすると
GitHub Actionsが自動で再デプロイします。
