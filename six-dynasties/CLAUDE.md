# 天下分裂 — 八王の乱から隋の統一まで

## このプロジェクトについて

291年（賈后が楊駿を誅し、八王の乱が始まる）から589年（隋が陳を滅ぼして
天下を統一する）までの中華を、**中華皇帝**として運営するターン制シミュレーション。

- **1ターン = 1年**、全299ターン
- **プレイヤー** = 中華皇帝（およびその宮廷）
- **中心となる遊び** = 外交と戦争。内政は外交・軍事の原資を作るための手段として扱う
- 西ローマ帝国末期シミュレーション（`claude/western-rome-sim-phase-0-73l154` ブランチ）と
  同じ設計思想で作ってあるが、**主題と仕組みは別物**

## 描きたい主題

このゲームが表現したいのは、次の2つのジレンマ。**すべての数値設計はこの2点に奉仕する。**

1. **宗室と方鎮の罠** — 晋は魏の孤立を戒めて宗室に封国と兵を与えた。国境はそれで
   守れたが、与えた兵はそのまま帝位を狙う手勢になった。**中央が兵を握れば辺境が落ち、
   辺境に兵を預ければ中央が倒れる。** 削藩すれば挙兵を招き、兵権を委ねれば野心が育つ。
2. **胡漢の取引** — 胡族を義従として雇えば、目先の戦線は安く埋まる。だが給が絶えれば
   寝返り、建国を許せば戸口と天命が削れていく。「今日を凌ぐ判断が、十年後の朝廷を殺す」
   という構造をプレイヤーに実感させる。

**敵はすでに垣の内にいる。** これが西ローマとの決定的な違いで、匈奴・羯・氐・羌・巴氐・
盧水胡・丁零・乞伏はこの時代すでに塞内へ移り住んでいる（内徙）。攻め戻る郷里を持たず、
州の中から国を建てる。地図でもそのとおりに表す。

## 状態モデル

パラメータは7つに固定する。**増やさない。**

| パラメータ | 意味 | 主な増減要因 |
|---|---|---|
| `treasury` | 国庫（銭・帛） | 税収 − 軍の維持費 − 歳幣 − 宮廷費 |
| `taxBase` | 戸口 | 州の支配度に比例。州の喪失と災厄で減り、屯田・土断で戻る |
| `centralArmy` | 中軍（禁軍） | 徴募・戦闘損耗。維持費が最大の支出 |
| `mandate` | 天命 | 勝利と譲歩で上昇。敗戦・簒奪・州の喪失で低下 |
| `gentry` | 士族の支持 | 増税で低下、免税特権の追認で上昇 |
| `princeLoyalty` | 宗室諸王の帰順 | 削藩で低下、鎮撫で上昇。低いほど挙兵する |
| `tribalLoyalty` | 胡族の帰順 | 義従胡への給の支払い実績に連動。絶えると寝返る |

君主・官職・宗室・胡族・北朝は7パラメータには含めず、`GameState` の別サブ構造として持つ。
**新しい資源にしない。既存の計算式への補正としてのみ作用させる。**

### 州

15州。淮水を境に**北8州・南7州**に分ける。

`Si`(司州) `Yong`(雍州) `Liang`(涼州) `Bing`(并州) `Ji`(冀州) `You`(幽州) `Qing`(青州) `Yu`(豫州)
／ `Yang`(揚州) `Jing`(荊州) `Jiang`(江州) `Yi`(益州) `Ning`(寧州) `Guang`(広州) `Jiao`(交州)

各州は `control`（0〜100）、`baseTax`、`baseTaxMax`、`garrison`、`region`、`holder` を持つ。

#### 江南は開発で伸びる

**朝廷が保っている州の `baseTax` は年ごとに伸び、南のほうが速い**
（`DEVELOPMENT_RATE_SOUTH` 0.0042 対 `DEVELOPMENT_RATE_NORTH` 0.0016）。
上限は南が初期値の2.9倍、北が1.35倍。

これはこの時代の最大の経済的事実であると同時に、**この模型が成立するための条件**でもある。
開発が無かったときは、北を失った朝廷は7州の収入（天下の36%）で中軍を養えず、
南渡した局が例外なく数十年で軍の脱走から滅んだ。東晋も宋も成立しない。

### 胡族の勢力

**14勢力。塞内に住む民と、塞外に郷里を持つ民に分ける。**

| 塞内に住む（内徙。郷里を持たない） | 塞外に郷里を持つ（地図では面） |
|---|---|
| 匈奴・羯・氐・羌・巴氐・盧水胡・丁零・乞伏鮮卑 | 拓跋鮮卑・慕容鮮卑・宇文鮮卑・柔然・高句麗・吐谷渾 |

柔然だけは**掠めるだけの民**として持つ（`raider`）。定住せず、掠めたその年のうちに
塞外へ引き揚げ、塞外での成長にも上限がある。

各勢力は `strength`、`strengthMax`、`stance`（`hostile`／`auxiliary`／`enfeoffed`）、
`location`、`reach`、`demand` を持つ。

#### 戦力には史実の天井を置く

`strengthMax` は前秦の氐を190、北魏の拓跋を240、柔然を90 というように、
**その民が史実で届いた高さ**に置く。これが無いと複利で伸び続け、320年代に
前秦も北魏も超える怪物ができあがった（299ターンの局では 6% の複利が11年で倍になる）。

#### 攻め入れる先は地理で決まる

`reach` に載っている州にしか攻め入れない。これが無かったときは、
守りが薄く豊かな州を天下じゅうから選ぶので、**遼東の慕容部が蜀（益州）を取る**局が出た。

#### 建国できるのは州を奪い切った勢力だけ

`foundKingdoms` は `province.holder === 勢力id` を要求する。「支配度が閾値を割っていれば」
でも建てられるようにしていたときは、朝廷がまだ握っている州の上に国が建った。
建国した勢力は敵ではなくなるので攻められもせず州も渡さない只の和平になり、
**1局に11か国が並んで天下統一が永久に成立しなくなった**（統一は敵国が残らないことを要する）。

### 首領は年で引く

この模型は年ごとの戦力の推移を持たないので、**脅威の山と谷は開始戦力ではなく
首領の能力で表す。** 石勒（軍事10）が河北を席巻した320年代、苻堅（9）が華北を
ひとつにした370年代、拓跋燾（10）が長江に迫った440年代は、同じ勢力でも別物の重さになる。
`data/leaders.json` から年で引く。

## 宗室の諸王 — 八王の乱

291〜311年は史実の八王をそのまま迎える（`data/princes.json`）。
それ以降は宗室の成人男子が封国を得る形で補充する。**南朝も宗室の乱で傾いた**ので、
この仕組みは八王の乱で終わらせない。

### 諸王は皇子から出す

補充の対象を傍系（`relation: 'kin'`）に限っていたときは、**312年以降の8割の年に
王がひとりもいなかった。** 生まれた子はみな `child` として記録されるので、
傍系は開始時の三人きりで増えないためである。宋の元凶の変も斉の諸王の相殺も
皇子どうしの争いで、南朝の諸王はいずれも皇子だった。
**「宗室に兵を預ければ中央が倒れる」という第一の主題は、皇子を封じてはじめて立つ。**

- **太子は封国を持たない。** 都にいて位を継ぐ者なので、成人した嫡子の筆頭は諸王に数えない
- **封国は終身。** 生まれた王に十年ほどの任期を置いていたときは、任期の切れた王が
  生きているのに二度と封じられず（去った王は再び現れない規則のため）、諸王が枯れた。
  王が去るのは没したとき・誅されたとき・位を継いだときだけ
- **一族の名簿から消えた者は封国も離れる。** 没しても位を継いでも `dynasty.members`
  から抜けるので、抜けた者を諸王に残していると、没した王が兵を挙げ、
  継いだ帝が自分自身に対して挙兵する
- 誅殺した王は**一族の名簿からも消す。** 残していたときは、誅したはずの王が
  のちに帝位を継いで現れた

一族の人数の上限は9人（`DYNASTY_MEMBER_MAX`）。6人にしていたときは成人が平均1.5人しかおらず、
うち一人は太子なので封じられる者がほとんど残らなかった。

**新しい家は一族を連れて興る**（`foundingKin`、成人1〜3人）。当主ひとりで興していたときは、
王朝が替わるたびに宗室が消え、子が生まれて成人するまでの十五年、諸王がひとりもいなくなった。
劉裕には弟の道憐・道規と数人の子がいて、宋はその一族ごと立っている。

ここまでで諸王は**初級1.9人／中級1.8人／上級1.6人**が立ち、
ひとりもいない年は19%／25%／35%まで下がった（直す前は80%）。

挙兵の判定は**天命に関わらず毎年引く。** 帰順の低さは確率を押し上げる要因として
線形に効かせる。閾値を下回った年にだけ引いていたときは、順調な朝廷では一度も起きず、
「宗室はいつ兵を挙げてもおかしくない」という緊張が出なかった。

**王が現れるのも兵を挙げるのも、朝廷が保っている州に限る。** 州の持ち主を見ずに
判じていたときは、胡族に奪われた州で王が挙兵し、そのまま州を胡族から取り上げた。
封国は朝廷が与えるものなので、朝廷の手にない土地には置けない。

**調整されている量は「一年あたりに天下で起きる挙兵の頻度」であって、
王ひとりあたりの確率ではない。** 名簿が埋まるように直したら諸王が倍になり、
同じ `PRINCE_REVOLT_BASE` のままでは挙兵も倍になって、中級の存続が54%から31%へ、
藩王の即位が19%から57%へ振れた。王の数を変えたら、この定数も割り戻す
（0.0035 → 0.0014）。

宗室に対する手は4つあり、**差し出すものがそれぞれ違う。**

| 行動 | 差し出すもの | 得るもの |
|---|---|---|
| 鎮撫 | `treasury` −95 | 帰順 +13 |
| 削藩 | 帰順 −16／野心 +1 | 諸王の兵の35%が中軍へ |
| 誅殺 | `mandate` −7／帰順 −22 | その王が消える |
| 兵権を委ねる | 野心 +2 | その州の守り +14／帰順 +6 |

## 城と主要都市

各州は治所（洛陽・長安・鄴・建康…）を持ち、**城の耐久**（`wall` / `wallMax`）を持つ。

**支配度が尽きても州はすぐには落ちない。そこから城攻めが始まる。**
耐久が尽きてはじめて城が陥ち、州が持ち主を変える。洛陽72・長安68・建康68 と
大城は高く、交州29・寧州32 と辺境の城は低い。囲まれていない年は少しずつ修復され、
「守りを固める」でも繕える。

耐久を地図に数と帯で描き込んだときは、城の密な中原で州名・支配度・城名・耐久・
「囲まれている」が四重五重に重なって読めなかった。**図には点と名だけを置き、
耐久は図の下の一覧で読ませる。** 囲まれている城にだけ細い帯を出す。

## 帝を称する — 天下に帝が並び立つ

### 胡族の首長は州を得れば帝を称する

`Faction.ambition`（1〜10）が**帝号を称するのに要る州の数**を決める。

| 野心 | 要る州 |
|---|---|
| 9〜10（匈奴・羯・氐・拓跋・慕容） | **1州** |
| 6〜8（羌・巴氐・丁零・乞伏） | 2州 |
| 5以下（盧水胡・宇文・柔然・高句麗・吐谷渾） | **3州（必ず称する）** |

劉淵は并州の一角で漢王を称し、石勒も襄国ひとつから趙王を名乗った。
称した勢力は国号（漢趙・後趙・前秦・前燕・代…）を号し、朝廷の天命はそのぶん削られる。

**帝号は失われもする。** 保つ州が0になった勢力は、その年のうちに号を降ろす。
与える判定だけを置いていたときは、北朝に州を呑まれた勢力が州を1つも持たないまま
589年まで「帝」を称し続けた（実測で53,262年ぶん）。**十六国が興っては滅んだのは、
称するのが易しく保つのが難しかったからで、称号だけが残ることはない。**

計測（150試行、`general`）: 帝を称した勢力は 延べ 初級1.8／中級2.9／上級3.2、
同時に並び立つのは最大 1.4／2.3／2.7、589年に残っているのは 0.7／0.8／0.6。
**延べと終局の差がそのまま十六国の興亡**である。

### 藩王が都を陥とせば帝位に即く

挙兵した王は年ごとに兵を蓄え、集まれば都を衝く。**陥とせばその王が帝位に即く。**
趙王倫が実際にそうしたように、宗室の乱は王朝の外へは出ない —
局は続き、帝が入れ替わるだけである。前の帝は廃され、担いだ兵はそのまま中軍になり、
天命は禅譲の閾値をわずかに超えるところまで戻る。代わりに士族の支持と宗室の帰順を失う。

**即位した王が押さえていた州は、すべて朝廷に戻る。** 戻していなかったときは、
挙兵している王が一人もいないのに「藩王の手」のままの州が残った。
即位したその王こそが朝廷なので、その手にある州は朝廷の州である。

**都を衝くには守りを1.25倍上回る兵が要る**（`PRINCE_MARCH_MARGIN`）。互角に近い兵でも
攻め上れるようにしていたときは、朝廷が細った局で挙兵がそのまま即位につながった。

即位した王が受け取る天命は36 — **禅譲の閾値（34）をわずかに超えるだけ**にしてある。
44 に置いていたときは簒奪が朝廷の立て直しとして働き、傾いた王朝が藩王の即位で
息を吹き返して禅譲が起きなくなった。趙王倫の簒奪は晋を立て直しはしなかった。

計測（150試行、`general`）: 藩王が帝位に即いた局は 初級5%／中級28%／上級38%。
**難易度が上がるほど宗室の乱が朝廷を倒す。** 兵の厚い朝廷は挙兵を討ち取れるが、
細った朝廷は都を守れない。

### 諸王も首長も三能力を持つ

皇帝と同じ**軍事・統治・人望**を持ち、野心を別の軸として添える。
諸王の能力は即位したときそのまま帝の能力になり、首長の能力は
`data/leaders.json` から年で引く（苻堅は統治9・人望10、石虎は統治2・人望2）。

**王は封国の号で呼ぶ。** 生まれた王を「晋の元帝睿」のように王朝名＋帝号で呼んで
いたときは、その王が即位したあと王朝が宋なのに帝の名が「晋の…」のままになった。

## 王朝の交替 — 禅譲

天命が閾値を割ると、実権を握る者へ位が渡る。**これは敗北ではない。**
局は続き、王朝の号が替わり、天命が62まで戻る。劉裕が晋から、蕭道成が宋から受けたのと
同じことが起きる。代わりに前の家に連なる士族と宗室は離れ、州は動揺する。

### 閾値は都督の能力で上がる

閾値は34だが、**在職の都督の能力1につき4ずつ押し上げる**
（`USURPATION_MARSHAL_THRESHOLD_PER_POINT`）。能力9の都督がいれば、天命が70でも位は渡る。

天命が尽きたときにしか位が渡らない作りにしていたときは、王朝の交替が1局に1.4回しか
起きなかった。**劉裕が晋から位を受けたのは、晋が衰えていたからではない** —
北伐に勝ち続けた将だったからである。蕭道成も陳霸先も同じで、
位を奪ったのはいずれも軍功を積んだ都督だった。
有能な都督を置くこと自体が危うい、という第一の主題がここにも要る。

### 天寿は一度だけ引く

`Person.lifespan` は**その人物が生まれたときに一度だけ**引く。毎年引き直していたときは、
年ごとに新しい寿命を抽選して「いまの年齢がそれを超えていたら没する」と判じていたため、
**40歳の帝が毎年32%で死んだ。** 代替わりが三年に一度になり、生まれた子は15歳の成人に
届かず、すべての継承が危機になって**1局に40回も王朝が替わった。**

### 天寿は帝だけのものではない

寿命を帝にしか当てていなかったときは、**一族の者が誰ひとり死ななかった。**
枠が三百年ぶん埋まったまま入れ替わらず、291年に生まれた弟が480年に八十九歳で
位を継ぐようなことが起きる。諸王もこの名簿から出るので、王の顔ぶれも入れ替わらない。

### 子は婚姻が無くても生まれる

`BIRTH_PROBABILITY` は皇后の有無に関わらず毎年引く（皇后がいれば上積み）。
婚姻を唯一の道にしていたときは、開始時の一族三人を使い切ったあと
すべての代替わりが継承危機になり、同じく王朝が十年ごとに替わった。
帝に後宮があるのは当たり前で、婚姻外交はそこに乗る上積みにすぎない。

### 位が渡る間隔に下限を置く

`ABDICATION_MIN_INTERVAL` は14年。受禅で戻る天命が十年で閾値まで落ち、
そのたびに次の実力者が位を受けるので、これが無いと士族の支持と宗室の帰順が
永久に0へ張り付いた。南朝の四代（宋斉梁陳）はいずれも数十年は保っている。

## 南渡と北朝

### 衣冠南渡

北の都をすべて失った朝廷は江南へ移る。**これは敗北ではない** — 317年の東晋がそうだったように、
都を移した朝廷は三百年続く。代わりに北の戸口と天命を失い、南渡してきた士族が朝廷を支える
（`gentry` +10）。南渡したあとにだけ**土断**が選べるようになる。

### 退く先は毎年探し直す

遷都を都が陥ちた**その年**にしか試みなかったときは、退く先が無かった一年をやり過ごすと
以後ずっと敵の手にある都に座り続け、毎年その分の動揺を受けた（実測で3,616年ぶん）。
`relocateIfCapitalLost` を毎年通し、**15州すべてに治所の名**（姑臧・味県・龍編…）を
与えて、保つ州が1つでもあれば必ずそこへ移れるようにしてある。
歴代の都が置かれた大城を先に選び、無ければ最も豊かで落ち着いた州へ退く。

### 北朝

**華北の州が3つ以上胡族の手に渡り、340年を過ぎると、そのうち最も強い勢力が
華北をまとめて北朝になる。** 前秦が376年に、北魏が439年に、実際にこうして生まれた。

胡族の手に渡った州の数を勢力ごとではなく**まとめて**数えるのが要。
「1つの勢力が5州を握るまで」を条件にしていたときは、州が勢力どうしで細かく分かれたまま
誰も閾値に届かず、**北朝が一度も立たない局ばかりになった**（隋も現れない）。

北朝は534年に東西へ裂け（`NORTH_SPLIT_STRENGTH_LOSS`）、581年に国号を隋と改める。
これが南に与えられる唯一の猶予になる。

## 勝敗

- **天下統一** — すべての州を朝廷が保ち、北朝も胡族の国もひとつも残っていない状態。
  達したその年に局が終わる（勝利）
- **存続** — 589年を迎えたが統一できなかった。天下をひとつにしたのは北の隋であり、
  南朝はやがて呑まれる。史実の陳と同じ結末
- **滅亡** — 保つ州が2を割るか、中軍が壊滅して国庫も尽きた

**統一の判定には「一度割れたこと」を要求する**（`fragmentedYear`）。291年の朝廷は
開始時点で天下を保っているので、割れる前に判じると1ターン目に勝ちになる。
また州の数だけで判じていたときは、挙兵した王を討ち取って州を取り戻すたびに
「天下を統一した」ことになり、294年に勝つ局が出た。

## 難易度

**初級／中級／上級**。難易度は**新しいメカニクスを足さない。** 既存の計算式に掛かる
倍率としてのみ作用させる。**中級はすべて 1.0**（調整済みの基準バランスがそのまま中級）。

| 倍率 | 作用する既存の計算式 | 対応する主題 |
|---|---|---|
| `incomeMultiplier` | 税収 | 循環の罠 |
| `foePowerMultiplier` | 戦闘解決（攻撃側戦力） | 循環の罠 |
| `auxiliaryEscalationMultiplier` | 義従胡の給の膨張率 | 短期と長期の取引 |
| `historicalSeverityMultiplier` | 有害な歴史イベントの発火確率と被害量 | 史実展開の再現度 |

`historicalSeverityMultiplier` は **上級 1.0 / 中級 0.6 / 初級 0.3**。緩和は
`harmful: true` のイベントにだけ掛ける。淝水の戦いや鍾離の大捷のような有益なイベントまで
弱めると、初級のほうが不利になるため。

## 計測

`npm run sim -- --trials 200` で通しの局を回す。方針AIは「危ういところを順に埋める」
だけの素朴な打ち手で、上手さの上限ではない。

### 守りを埋めるだけの方針（`general`、150試行）

| | 初級 | 中級 | 上級 |
|---|---|---|---|
| 存続 | 100% | 59% | 5% |
| 統一 | 0% | 0% | 0% |
| 滅亡 | 0% | 41% | 95% |
| 王朝の交替 | 1.7回 | 2.0回 | 1.8回 |
| 北朝が立った局 | 97%（平均359年） | 99%（342年） | 97%（341年） |
| 帝を称した胡族（延べ／同時最大／終局） | 1.8／1.4／0.7 | 2.9／2.3／0.8 | 3.2／2.7／0.6 |
| 藩王が帝位に即いた局 | 5% | 28% | 38% |
| 諸王が立っている人数 | 1.9人 | 1.8人 | 1.6人 |
| 諸王がひとりもいない年 | 19% | 25% | 35% |

### 北伐に枠を割く方針（`unifier`、150試行）

| | 初級 | 中級 | 上級 |
|---|---|---|---|
| 存続 | 13% | 33% | 3% |
| 統一 | **66%** | **20%** | **11%** |
| 滅亡 | 21% | 47% | 86% |
| 北朝が立った局 | 31% | 79% | 86% |

**北伐は生存を削る。** 中級で見ると、守りを埋めるだけなら59%が589年まで保つのに対し、
北伐に枠を割くと保つのは33%まで落ちる。代わりに20%が天下を統一する。
「延命か、統一か」がそのまま取引になっている。

守りを埋めるだけなら北朝は**ほぼ必ず立つ**（97〜99%）ので、南北朝から隋へ至る筋は
黙って見ていれば必ず通る。北朝が立たない局は、華北を押し返した局だけである。

**王朝の交替は1局に2回前後。** 一族が尽きる継承危機だけで家が替わっていた頃は3.6回
だったが、あれは新しい家が一族をひとりも連れずに興り、次の代でまた尽きていたためで、
交替の多さは仕組みの穴が生んだ数だった。いまは幼帝が立って成人の一族が絶えたところへ
実力者が受禅する形と、有能な都督がそのまま位を受ける形の二つで替わる。

### 不変条件の点検

`npm run audit` は数字の釣り合いではなく、**あってはならない状態**を探す。
三通り — 値域と整合（でたらめな手を毎年打たせる）、会戦と保存の経路、
そして「壊れてはいないが筋が通らない」状態。**1件でも挙がれば直すべき不具合**として扱う。
下の表の症状はいずれもこれで見つけた。いまは 180局／11,874ターン、会戦1,627回、
筋の点検180局／19,808ターンを通して破れなし。

**ただし点検は「壊れていないこと」しか見ない。** 諸王が8割の年に一人もいない、
一族の者が誰も死なない — この種の欠落はどの不変条件にも触れないので挙がってこない。
主題に関わる数（諸王の人数、挙兵の頻度、王朝の交替の回数）は別に測って見張る。

## コアループ

`tick(state, actions, seed) => newState` の中で、必ずこの順序で処理する。

1. 収入
2. 支出（義従胡の給の清算 → 国庫が負なら脱走 → 帰順が尽きていれば離反）
3. プレイヤー行動の適用
4. 胡族の手番 — 成長・移動・侵攻（支配度→城攻め）・建国 → 要求
5. 北朝の手番 — 華北の統合と南征／郷里の奪還／挙兵した王の増強と都への進撃
6. 都の攻防 — 陥落・退く先の探し直し・南渡・都を押さえられているあいだの動揺
7. 支配度・城の修復・開発・戸口の更新
8. 天命の判定 — 自然減 → 禅譲 → 宗室の挙兵 → 刺史の反乱
9. 王朝と官職の更新 — 加齢・出生・寿命と暗殺・継承・任期・候補の入れ替え
10. 歴史イベントの発火判定
11. 帝号の判定 — 称号を与え、また取り上げる

**帝号の判定は最後に置く。** 州の持ち主が動きうる処理をすべて終えてから数えないと、
そのあとで州を失った勢力が、その年のあいだ「州を持たない皇帝」として残る。

## プレイヤーのアクション

1ターンに選べるのは**2つまで**。何を諦めるかを選ばせることがこのゲームの本体。

- **宗室** — 鎮撫／削藩／誅殺／兵権を委ねる／挙兵した王の討伐
- **胡族** — 歳幣／義従として雇う／要求への応答／郷里への遠征
- **軍事** — 中軍の派遣／州の守りを固める／州で募兵／徴募／都督の任免／北伐／会戦
- **内政** — 増税／軍の再編／士族の機嫌を取る3手／屯田／土断／遷都
- **官職** — 録尚書事と刺史の任免／婚姻

### 行動枠を消費しない行動

**要求への応答**（相手が始めたことへの返事であって、こちらが1年を費やす行動ではない）と
**官職の任命**（録尚書事1人と刺史15人は任期がばらばらに切れるので、枠を食わせると
ほぼ毎年どちらかの任命に追われる）。どちらも無償ではない — 応答は必ず何かを恒久的に削り、
任命には金がかかる。**解任のほうは枠を消費させる**（天命が戻る政治的な行為なので
無料の上振れにしない）。

## 会戦と戦場

会戦は中軍の85%を投じる一度きりの決戦。**率いる者が要る** — 帝自身（軍事6以上）か
都督がいなければ挑めない。軍を率いたのは帝ではなく都督だった、というこの時代の形を
そのまま条件にしてある。

会戦を選んだ年は**戦闘専用の画面に切り替わる。** 左翼・中軍・右翼の3つの戦列に
歩兵・騎兵・弓兵を配り、激突ごとに前進・迂回・退却を選ぶ。騎は歩に、歩は弓に、弓は騎に強い。

- **布陣の段は一隊置いても終わらせない。** 一隊置いた時点で命令の段へ移していたときは、
  控えの一覧が消えて残り五隊を置けないまま戦いが始まった
- 矢の向かう先は `resolveTarget()` を core から引く。**表示側で引き写さない**
  （正面が空いた戦列が隣へ回り込む規則を描き落とすため）
- **頭数は兵力の平方根で取る。** そのまま割っていたときは、兵力8の隊が縦一列3人に
  潰れて兵に見えなかった
- **戦況の記述はどちらの戦列かを必ず書く。** 両軍とも左翼・中軍・右翼を持つので、
  「右翼が前進して右翼を崩した」ではどちらがどちらを崩したのか読めない
- 敵は図の上端＝遠くに立つので、**兵ひとりを小さく描く**（`FOE_FIGURE_SCALE`）

## 地図

`scripts/generate-map.ts` が Natural Earth と world-atlas から州ごとの SVG パスを
生成し、`src/ui/mapPaths.ts` に書き出す。**実行時に地図ライブラリは使わない。**
再生成にはネットワークが要る（`npm run map`）。

州域は魏晋期の近似として現代の行政区画を組み合わせている。省を割ることはできないので、
**1つの省はどれか1つの州にだけ属す**ように配る。地図の色分けとデータが食い違わないことを優先する。

塞外の勢力を図の上端に駒でも並べていたが、この時代に郷里を持つ民はちょうど6つの郷里の面と
一対一で重なるので、同じものが二度出るだけだった。兵力は郷里のラベルに添えてある。

## 直した不具合

計測と通し遊びで見つかったもの。**どれも症状を先に書いてから直している。**

| 症状 | 原因 | 直し方 |
|---|---|---|
| 誅殺した趙王倫が翌年また封国を得て現れた | 去った理由を覚えず、その年の名簿にいないことだけを見ていた | `retiredPrinceIds` に控え、一度去った王は二度と出さない |
| 嶺南の交州が内から荒れただけで北朝領になった | 支配度が尽きた州を、攻めた者を見ずに北朝へ渡していた | `TurnModifiers.besieged` にその年の攻め手を控え、そこからのみ持ち主を決める |
| 即位した藩王の名が「晋の…」のまま、王朝は宋 | 王を王朝名＋帝号で名づけていた | 封国の号（武陵王・江夏王…）で呼ぶ |
| 帝を称した首長の説明が「の主が帝を称している」 | 名の伝わらない年の予備の呼び名が空文字だった | `emperorName` を null にし、呼び名は表示側で補う |
| 布陣で一隊置くと残り五隊を置けないまま戦いが始まった | 一隊置いた時点で命令の段へ移していた | 段を進めるのは「この布陣で戦う」を押したときだけ |
| 州を1つも持たない勢力が589年まで帝を称し続けた | 号を与える判定だけがあり、失う判定が無かった | 保つ州が0になった勢力の号を毎年取り下げる。判定は年の最後に置く |
| 都を敵に押さえられたまま何年も動かない朝廷があった | 遷都を都が陥ちたその年にしか試みなかった | `relocateIfCapitalLost` を毎年通し、15州すべてに治所名を与えて退く先を絶やさない |
| 挙兵している王が一人もいないのに藩王領の州が残った | 王が即位したとき、その手にあった州を朝廷へ戻していなかった | 即位のときに藩王の手の州をすべて朝廷へ戻す |
| 胡族に奪われた州で宗室の王が挙兵し、その州を奪い返した | 王の出現と挙兵が州の持ち主を見ていなかった | 王が現れるのも兵を挙げるのも朝廷が保つ州に限る |
| 羯の戦力が 167／150 と史実の天井を超えた | 成長の側だけ天井を見ており、歴史イベントの増分が素通りした | イベントの効果も `strengthMax` で頭を押さえる |
| 古い保存を読み込むと年送りで `retiredPrinceIds is not iterable` で落ちた | 状態に欄を足したのに保存の版を上げていなかった | 版を2に上げ、版が合っていても欄の欠けを読み込み時に確かめる |
| 312年以降、8割の年に諸王がひとりもいなかった | 補充を傍系に限っており、生まれた子はみな `child` なので傍系が増えなかった | 皇子を含む宗室の成人男子から封じる。太子は除く。封国は終身にする |
| 291年生まれの弟が480年に八十九歳で位を継いだ | `Person.lifespan` を帝にしか当てておらず、一族の者が誰も死ななかった | 一族も天寿で没する。没した王は封国を離れ、その州は朝廷へ戻る |
| 誅殺したはずの王がのちに帝位を継いで現れた | 諸王の名簿からは消したが、一族の名簿には残していた | 誅殺で `dynasty.members` からも消す |
| 同じ年に二人の王が同じ封国へ封じられた | 封じるたびに空いている州の一覧から取り除いていなかった | 一つの州に二人の王は立たない |
| 王朝が替わるたびに宗室が消え、十五年ほど諸王がいなくなった | 新しい家を当主ひとりで興していた | 成人1〜3人の一族を連れて興る |
| 禅譲を挟んだ州が、拠る王もいないのに藩王領のまま残った | 前の家の諸王を降ろすとき、挙兵中の王の封国を戻していなかった | 位が渡った年に藩王領をすべて朝廷へ戻す（点検で671件として挙がった） |

## 技術構成

- React + TypeScript + Vite + Tailwind v4
- 状態は純関数 `tick()` に集約。UI は `core/` を呼ぶだけで計算式を持たない
- 年送りのたびに `localStorage` へ自動保存。書き出し・読み込みも可能。
  **状態に欄を足したら `save.ts` の `VERSION` を上げる**（読めないものは断る）
- `npm run sim` で釣り合いを測り、`npm run audit` で不変条件を検める
- GitHub Actions → GitHub Pages
