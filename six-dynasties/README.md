# 天下分裂 — 八王の乱から隋の統一まで

291年、賈后が楊駿を誅した。八王の乱がここに始まる。
589年、隋が陳を滅ぼして天下はひとつになる。
そのあいだの三百年を、**中華皇帝**として凌ぐターン制シミュレーションです。

**1ターン = 1年、全299ターン。** 1年に打てる手は2つだけ。

## この三百年で起きること

晋は魏の孤立を戒めて宗室に封国と兵を与えました。国境はそれで守れましたが、
与えた兵はそのまま帝位を狙う手勢になります。

そして**敵はすでに垣の内にいます。** 匈奴・羯・氐・羌はこの時代すでに塞内へ移り住んでおり
（内徙）、并州にも雍州にも冀州にも暮らしています。彼らを義従として雇えば戦線は安く埋まりますが、
給が絶えれば寝返り、建国を許せば戸口と天命が永久に削れていきます。

- **中央が兵を握れば辺境が落ち、辺境に兵を預ければ中央が倒れる**
- **今日を凌ぐ判断が、十年後の朝廷を殺す**

洛陽を失えば朝廷は江南へ移ります。それは敗北ではありません — 東晋はそこから百年続きました。
天命が尽きれば位は実権を握る者へ渡ります（禅譲）。それも敗北ではありません —
晋から宋へ、宋から斉へと位は渡り続けました。**王朝の号が替わっても、局は続きます。**
**有能な都督を置けば、その者が位を受ける日も早まります。** 劉裕も蕭道成も陳霸先も、
勝ちすぎた将でした。

## 天下に帝が並び立つ

**藩王が洛陽を陥とせば、その王が帝位に即きます。** 趙王倫がそうしたように、
宗室の乱は王朝の外へは出ません — あなたはその王として遊び続けます。
諸王は宗室の成人男子（太子を除く皇子と傍系）から封じられ、
封国は終身です。鎮撫するか、削藩するか、兵権を委ねるか、誅すか —
**どれを選んでも何かを差し出すことになります。**

**異民族の首長も、州を得れば帝を称して国号を号します。** 要る州の数は野心で決まり、
野心の高い民（匈奴・羯・氐・拓跋・慕容）は**一州**で、低い民も**三州を得れば必ず**称します。
劉淵は并州の一角で漢王を称し、石勒も襄国ひとつから趙王を名乗りました。

**称号は保つほうが難しい。** 州をすべて失った勢力はその年のうちに号を降ろします。
一局のあいだに帝を称するのは延べ2〜3勢力、同時に並び立つのは多くて1〜3、
589年まで残るのは1つに届きません。十六国が興っては滅んだとおりです。

各州の治所は**城の耐久**を持ちます。支配度が尽きても州はすぐには落ちず、
そこから城攻めが始まります。洛陽・長安・鄴・建康・江陵・成都は大城で、
辺境の城より長く保ちます。

589年までに天下をひとつにできなければ、統一するのは北の隋になります。

## 武将を集める

**官職は席であり、武将は人です。** 291〜589年の66人（張華・王導・陶侃・桓温・謝安・
謝玄・劉裕・檀道済・韋叡・陳慶之・陳霸先…）が、その在世の年に在野として現れます。

```
在野 →（登用）→ 配下 →（任命）→ 都督・録尚書事・刺史 →（罷免）→ 配下
                    →（出征）→ 部隊を率いて州へ  →（召還）→ 配下
```

一人ずつ**統率・武力・知力・政治・魅力**と**個性**を持ちます。都督と部隊の将には統率が、
刺史と録尚書事には政治が問われます。個性は猛将・名将・鉄壁・神算・屯田・能吏・
人望・高潔・野心家・懐柔・酷吏・名士の12種で、**効くのは官に就けた者だけ**です
（抱えているだけでは何も起きません）。

忠誠は年ごとに冷めます。尽きた者は去り、**州や兵を預けていればそれごと離れます** —
王敦も桓玄も侯景もそうしました。恩賞で買い戻せますが、金がかかります。

登用・恩賞・任命は行動枠を使いません（詔一本の話なので）。代わりに金がかかり、
**登用は断られることがあります**（金は戻りません）。

## 軍を発する

**失った州は、詔ひとつでは戻りません。** 中軍の55%を割いて将に預け、
都から州へ、州から州へ動かして城を囲みます。

```
中軍 →（出征）→ 部隊 →（行軍・年をまたぐ）→ 城を囲む →（陥落）→ 州が戻る
```

15の州は隣り合いで繋がっていて、**敵地を通る路は自領の4倍に数えます** —
部隊は回り道ができるならまわります。洛陽から涼州は三州の道のりで、
一年に進めるのは一州だけ。同時に出せる軍は3つまでです。

**互角では城は落ちません。** 一年に削れる耐久は攻守の比で決まり、
守り手に届かない軍は何年囲んでも一寸も削れません。囲んでいるあいだ守備隊は痩せますが、
攻め手も年ごとに兵を失います。**敵の手にある城も、囲まれていない年は繕われます。**

野に出ている兵は都の禁軍より高くつきます（兵站のぶん）。
**将を失えば軍は散り**、忠誠が尽きれば**兵ごと離れます** —
王敦も桓玄も侯景も、朝廷が与えた軍を朝廷へ向けました。

軍を発することだけが1年の手で、進軍先を改めるのも召還も詔で足ります。
地図には将の名と兵を載せた札が立ち、まだ着いていない軍には目指す州へ点線が引かれます。

## 人には顔がある

帝・皇后・藩王・都督・録尚書事・刺史・胡族の首長・北朝の主には肖像がつきます。
**冠がそのまま身分です** — 冕冠の旒は天子、花釵冠は皇后、遠遊冠は藩王、
進賢冠は文官、兜は都督、貂の帽は胡族の首長。

七役すべてに描いた画が入っています（129枚）。
画の無い年格好は近い年の画に落ち、それも無ければ同じ決まりで組み立てた肖像が出ます。

顔はその人物ごとに決まっていて、年を重ねると髭が伸び、白くなります。
即位した藩王は王だったときの顔のまま帝になり、歴代の一覧に並ぶ顔も
在位中に見た顔と同じです。

## 皇后を迎える

士族の家門・胡族・北朝のいずれかと婚姻を結べます。申し出の一覧に出ている顔と
年・人望が、そのまま迎える皇后のものです。**后は迎えているあいだ毎年働きます** —
士族の女なら士族の支持を、和親の后なら胡族の帰順を、北朝の公主なら天命を支えます。
子が生まれた年に縁はもう一度効き、代が替われば后も替わります。

## 遊びかた

1. 難易度と初代の帝の名を決めて始めます
2. **天下** — 地図で州の支配度、主要都市と城の耐久、胡族の位置、
   出征軍の位置と戦線を読みます
3. **朝廷** — 帝・諸王・胡族の首長の能力（軍事・統治・人望・野心）と、
   誰が帝を称しているかを見ます
4. **行動** — その年の手を2つまで選びます
5. **次の年へ** で1年進みます

会戦を選んだ年は戦場の画面に移り、左翼・中軍・右翼に隊を配って
前進・迂回・退却を指示します。

年を送るたびに端末へ控えが残るので、閉じても続きから遊べます。
「記録」から書き出して別の端末へ持っていくこともできます。
仕組みが変わった版のセーブデータは、黙って壊れるより断るほうがよいので読み込みません
（その旨を表示します）。

## 勝敗

| 結末 | 条件 |
|---|---|
| **天下統一** | すべての州を朝廷が保ち、北朝も胡族の国も残っていない |
| **存続** | 589年を迎えたが統一できなかった。天下は隋のものになる |
| **滅亡** | 保つ州が2を割るか、中軍が壊滅して国庫も尽きた |

功業 = 保った州 × 戸口 × 天命。難易度が違えば比べられません。

## 難易度

三段は**素朴な打ち手が589年まで保つ割合**で並べてあります。

| | 内容 | 素朴に守るだけなら |
|---|---|---|
| **初級** | 収入に余裕があり、災厄も半分に届かない。ただし史実の出来事そのものは起きます | 93%が589年を迎える |
| **中級** | 調整の基準。史実より朝廷に有利で、災厄は半分ほど | 55% |
| **上級** | 史実に近い。永嘉の乱も侯景の乱もほぼ確実に起き、四分の三の局が江南へ落ちます | 20% |

**上級でも手はあります。** 中軍を厚く積んで守れば37%、その軍で出征すれば
36%が保ち14%が天下を統一します。南朝が宋・斉・梁・陳と替わりながら589年まで
続いたように、**呑まれて消えるのが上級の既定路線ではありません。**

素朴な打ち手で通した計測（200試行）です。

| | 初級 | 中級 | 上級 |
|---|---|---|---|
| 素朴に守るだけ（中軍90） | 存続93% | 55% | 20% |
| 積んで守る（中軍150） | 87% | 76% | 37% |
| 積んだ軍で出征する | 存続33%／**統一60%** | 49%／**29%** | 36%／**14%** |

**統一を狙うには、まず中軍を積まねばなりません。** 薄い中軍から割いた部隊は、
城に取りつく前に崩れます。積んだうえで守りに徹すれば中級76%まで保ちますが、
その軍を野へ出すと保つのは49%へ落ち、代わりに29%が天下を統一します。

**軍を積むことと、積んだ軍を使うことは別の判断**です。
初級にいたっては、積みすぎるとかえって損をします（維持費だけが出ていくため）。

## 史実の出来事

賈后の専権、趙王倫の簒奪、劉淵の挙兵、永嘉の乱、長安陥落、王敦の乱、蘇峻の乱、
冉閔の殺胡令、桓温の北伐、淝水の戦い、孫恩の乱、桓玄の簒奪、劉裕の長安回復、
元嘉の北伐、孝文帝の洛陽遷都、鍾離の大捷、六鎮の乱、陳慶之の洛陽入城、侯景の乱、
江陵陥落、北周の北斉併合、楊堅の隋建国 — 40近い史実の出来事が、条件を満たした年に起きます。

桓温・謝玄・劉裕・檀道済・韋叡・陳慶之・陳霸先といった名将は、
その在職の年に都督として迎えられます。石勒・苻堅・慕容垂・拓跋燾も、
その在位の年にそれぞれの民を率いて現れます。

## ローカルで動かす

```bash
npm install
npm run dev
```

```bash
npm run typecheck            # 型検査
npm run sim -- --trials 200  # ヘッドレスで通しの局を回して結末の分布を出す
npm run sim -- --strategy unifier --army 150   # 出征に枠を割く打ち手で測る
npm run audit                # 不変条件の点検（あってはならない状態を探す）
npm run portraits            # public/portraits/ の画を数えて一覧を作り直す
npm run map                  # 地図の再生成（ネットワークが要る）
```

## 公開

`.github/workflows/pages-six-dynasties.yml` が、このブランチへの push で
ビルドして GitHub Pages に載せます。リポジトリの Settings → Pages → Source を
「GitHub Actions」にしておいてください。

> GitHub Pages はリポジトリにつき1つのサイトしか提供しないので、
> このリポジトリの他のアプリ（`main` の NY旅のしおり、`claude/western-rome-sim-phase-0-73l154`
> の西ローマ帝国シミュレーション）とは**最後に push したものが表示されます。**

## 技術構成

- React + TypeScript + Vite + Tailwind v4
- 状態は純関数 `tick(state, actions, seed)` に集約。UI は計算式を持たない
- 地図は Natural Earth / world-atlas から静的な SVG パスへ変換済み（実行時に地図ライブラリを使わない）
- `localStorage` への自動保存とファイルへの書き出し

設計の意図と、調整の過程で分かったことは [`CLAUDE.md`](CLAUDE.md) に書いてあります。
